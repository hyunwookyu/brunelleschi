# 사전분포 채움 방식 전환 계획

## 1. 무엇이 바뀌는가

기존: 측정 가능한 것만 확정하고 나머지는 `unresolved`로 남긴다.
변경: 측정 가능한 것은 그대로 확정하고, **미결정 자유도를 사전분포로 채우되 그 사실을 표시한다.**

파이프라인 구조는 유지된다. 한 단계가 삽입될 뿐이다.

```
스케치
 → 정규화 → 프리미티브 → 볼륨            [유지]
 → 소실점 → 카메라 복원                    [유지]
 → 측정 가능 자유도 확정                    [유지]
 → 미결정 자유도를 사전분포로 채움          ★ 신규
 → 결정론 기하 생성                        [유지]
 → 측정/추정 구분 표시                      ★ 확장
 → 사용자 조정 → IR 갱신                   [확장]
```

**렌더 이미지를 경유하지 않는다.** 렌더에는 3D 정보가 없어 image-to-3D를 다시 돌려야 하고, 그 출력은 카메라도 치수도 없는 메쉬다. 정보를 잃었다 다시 추정하는 왕복이 생기고, 파라메트릭이 아니라 사후 조정도 비싸진다.

## 3. 사전분포 설계

### 3.1 무엇을 채우는가

측정으로 확정되지 않는 자유도만 채운다. 확정된 것은 건드리지 않는다.

| 미결정 항목 | 발생 조건 | 채움 근거 |
|---|---|---|
| 종횡비 | 2점 (상대폭 0.894) | 실내 비례 분포 + 1-bis 구간 |
| 깊이 | 1점 (f 미결정) | 실내 비례 분포 + 시거리 게이트 |
| 전역 스케일 | 앵커 없음 | 용도별 대표 치수 |
| 층고 | 항상 | 도메인 상수 (오피스 3.9~4.2m 등) |
| 축 라벨 | 2·3점 (수학적 동점) | **채우지 않는다** — 토글로 사용자에게 |

축 라벨을 제외하는 이유: 사전분포로 고를 근거가 없고(회전 대칭), 틀리면 폭·깊이가 반대인 모델이 조용히 나온다. 발생률 28.75%로 무시할 수 없다.

### 3.2 분포의 출처

임의값은 "그럴듯함"이 아니다. 세 경로가 있고 순서대로 시도한다.

**a. 도메인 상수 테이블** (즉시)
용도별 층고, 스팬, 코어 비율. 이미 계획 §5.2에 오피스 기준이 정리되어 있다. 확실하지만 종횡비는 못 준다.

**b. 통계 코퍼스** (수집 필요)
실내 평면의 종횡비 분포. 공개 데이터가 있다 — RPLAN, LIFULL HOME'S, CubiCasa5K 등 평면도 데이터셋. 방 단위 종횡비를 뽑으면 된다.
용도(거실/침실/사무실)별로 나누면 §4의 naming과 연결된다.

**c. VLM 판단** (폴백)
스케치를 보고 대략 비례를 말하게 한다. 통계보다 맥락을 본다.
출력은 닫힌 스키마, 기하 검증이 뒤집을 수 있어야 한다.

### 3.3 표본 추출

```
1. 측정 확정값을 제약으로 고정
2. 1-bis 구간을 지지집합으로 사용
3. 그 안에서 사전분포 밀도가 최대인 값 선택 (MAP)
4. 시거리 게이트(0.5W~3W) 통과 확인, 실패 시 재추출
5. 선택값과 출처를 IR에 기록
```

무작위 샘플링이 아니라 MAP이다. 결정론적이어야 같은 스케치가 같은 결과를 내고, 파리티 테스트가 유지된다.

## 4. IR 변경

루트 필드를 늘리지 않는다. 값마다 출처를 붙인다.

```json
{
  "volumes": [{
    "id": "hall",
    "footprint": [...],
    "height": 4.0,
    "provenance": {
      "footprint": "measured",
      "aspect":    "prior:corpus/office",
      "height":    "prior:constant",
      "scale":     "unresolved"
    },
    "alternatives": {
      "axis": [{...}, {...}]
    }
  }]
}
```

`provenance` 값의 도메인:

| 값 | 의미 | 표시 |
|---|---|---|
| `measured` | 스케치에서 직접 | 실선 |
| `derived` | 측정값에서 전파 | 실선, `~` |
| `prior:*` | 사전분포에서 채움 | **파선 + 회색** |
| `user` | 수동 입력·발화 | 실선, 굵게 |
| `unresolved` | 채우지 못함 | 표시 없음 |

`alternatives`는 축 라벨처럼 동점인 항목의 복수 해를 담는다.

**중첩 필드이므로 루트 7 유지.** 12필드 제한(§13)에 여유가 남는다.

---

## 5. 표시 정책 (§3.5 확장)

기존 3단(명시/범위/전파)에 추정이 추가되어 4단이 된다.

- **측정**: 불투명 면, 실선 엣지, 치수 실선
- **전파**: 실선 엣지, 치수 `~` 표기
- **추정(prior)**: 반투명 면, 파선 엣지, 치수 회색 파선
- **미결정**: 치수 표기 없음

3D 뷰에 요약 배지를 둔다: `측정 6 / 추정 3 / 미결정 1`
누르면 추정 항목 목록이 열리고, 각각을 눌러 수정할 수 있다.

**이것이 낙관 편향 방어선이다.** 프로젝트에서 반복된 실패 유형(마우스 precise 판정, 합성이 쉽다는 가정, plane_iou 둔감성)이 사용자 쪽에서 재현되는 것을 막는다.

## 6. §6 질의 루프 변경

대상이 `unresolved`에서 **`prior`로 채운 값 중 영향도 높은 것**으로 바뀐다.

기존 분기 영향도 계산이 그대로 쓰인다. 다만 B-2에서 확인된 대로 부피 서명만으로는 90° 뒤바뀜을 놓치므로 `shape_signature` 병용이 필수다.

우선순위:
1. `alternatives`가 있는 항목 (축 라벨) — 토글로 즉시 해소
2. 영향도 높은 `prior` (스케일 2.40, 축 2.00, 높이 0.3~0.5)
3. 영향도 낮은 `prior` — 묻지 않고 유지

## 8. 우선순위 변경

### 8.1 하락

**다중 뷰 정합 (5번).** 종횡비 자유도를 메우는 유일한 자동 경로였는데, 사전분포가 그 역할을 대신한다. 정확도는 다중 뷰가 높지만 비용이 크고, 사용자가 여러 장을 그려야 한다.

여전히 가치는 있다 — 측정으로 확정하는 것이 추정보다 낫고, 축 모호도 전역에서 하나로 준다. 순서만 뒤로 민다.

**타원 선행 작도.** 원 하나로 계량구조가 결정되므로(8.4절) 종횡비가 확정된다. 사전분포보다 정확하다. 다만 사용자가 원을 그려야 하고, 프리핸드 타원 정확도가 미측정이다.

`prior` 대신 `measured`를 얻는 경로이므로 선택 기능으로 남긴다. 원이 검출되면 8.7절 d=(A/B)√(ab)로 확정하고, 없으면 사전분포로 간다.

### 8.2 유지

**C-0 축 뒤바뀜 성격 규명.** P-5 토글의 전제다. 게이지 자유도로 판명되면 토글이 불필요해지고 P-5가 빠진다.

**기준면 선행 (C-1).** 종횡비에는 효과가 없다고 이미 정리됐으나, 획 그룹핑·구축선·지면 판별에는 유효하다. 사전분포와 무관하게 측정 층을 개선한다.

### 8.3 상승

**§14 로깅.** 사용자가 조정한 값이 곧 사전분포의 정답이다. `prior` 값과 사용자 수정값의 쌍이 쌓이면 분포를 갱신할 수 있다. 라벨링 비용 0.

이 방식에서는 로깅이 부가 기능이 아니라 사전분포 개선의 주 경로가 된다.

## 9. 위험

**추정이 측정처럼 보이는 것.** §5 표시 정책이 방어선이고, 이게 약하면 이 방식 전체가 위험해진다. P-4를 얇게 만들면 안 된다.

**축 뒤바뀜의 무증상화.** 28.75%가 조용히 지나가면 폭·깊이가 반대인 모델을 받는다. P-5 토글로 대응하되, C-0에서 실제 형태 오류로 판명되면 우선순위를 올려야 한다.

**사전분포의 자기강화.** §14 로깅으로 분포를 갱신하면, 시스템이 제안한 값이 다음 분포에 반영된다. 사용자가 수정하지 않은 것이 "정답"으로 쌓인다. 수정 여부를 약한 신호로만 취급하고, 명시적 수정만 강한 신호로 쓴다.

**조정 비용 전제.** "나중에 조정하면 된다"가 성립하려면 파라메트릭 IR을 유지해야 한다. 메쉬 생성 경로로 가면 이 전제가 깨진다. 렌더 경유를 배제하는 이유.

## 10. assumptions 추가

- "사전분포로 채운 값이 그럴듯하다" — P-11이 측정. 참값 대비 오차 분포
- "사용자가 추정값을 구분해 인식한다" — P-4 표시 정책의 전제. 미검증
- "조정 왕복이 값싸다" — P-10이 측정. §1의 왕복 횟수 지표
