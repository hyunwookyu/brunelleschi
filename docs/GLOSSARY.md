# 용어

이 저장소가 쓰는 말. 세션이 새 용어를 만들면 **여기 한 줄 더한다.**

## 시험

| 말 | 뜻 |
|---|---|
| **원장** | 잰 숫자를 적어 두는 장부(`stage0/out/*.json`). 여러 라운드에 걸쳐 값을 비교하려면 남아 있어야 한다. `LEDGER=1` 없이는 한 바이트도 안 써진다 — 기준선을 실수로 덮는 것을 막는다(#90 · #94 · #99) |
| **팔** | 앱을 대신 조작하고 재는 시험 코드. 「팔이 빨갛다」 ≠ 「앱이 틀렸다」 |
| **게이트** | 라운드를 닫으려면 통과해야 하는 조건. **반드시 숫자다** |
| **초록 / 빨강** | 통과 / 실패 |
| **스펙 / 칸** | 시험 파일 하나 / 시험 하나 |
| **e2e / 단위** | 브라우저를 열어 클릭까지 하는 시험 / 함수만 부르는 시험 |
| **전량** | 시험 전부 |
| **플레이크** | 코드가 같은데 어떤 때는 통과하고 어떤 때는 실패하는 시험 |
| **워커** | 시험을 동시에 돌리는 일꾼 수. 시간을 재는 원장은 이 값에 좌우된다 |
| **dpr1 / dpr2** | 보통 화면 / 고해상도 화면 |
| **픽스처** | 시험용으로 미리 만들어 둔 장면 |
| **무회귀** | 전에 되던 것이 그대로 된다 |
| **반증** | 일부러 망가뜨려 「내 계측이 진짜 재고 있나」를 확인하는 것 (D-3) |
| **귀속** | 이 빨강이 이번 라운드 탓인지 원래 그랬는지 가리는 것 |
| **부모 트리** | 이번 라운드 착수 전의 코드. 귀속을 가릴 때 여기서 같은 시험을 돌린다 |

**실행 셋** (web2-54가 만들었다)

```
e2e:green    병렬 · 계측 넷 제외 · dpr2는 목록만    빠른 확인
e2e:night    전량 · dpr2 전부 · 계측 포함          마감 검증
e2e:ledger   LEDGER=1 · 워커 1 · 스펙 하나씩       원장을 쓸 때만 (#99)
```

## 배포

| 말 | 뜻 |
|---|---|
| **커밋 / 해시** | 저장된 판 하나와 그 이름표 (`4eecab5`) |
| **갈래** | 본선(main)을 안 건드리고 따로 작업하는 가지 |
| **마감** | 라운드 끝내는 절차 — 전량 돌리고 · 보고 쓰고 · 배포하고 · 문서 갱신 |
| **deploy-check** | 실제 사이트가 그 커밋을 띄우는지 확인하는 스크립트. **「푸시했다」와 「배포됐다」는 다르다**(#58) |

## 문서

| 말 | 뜻 |
|---|---|

| **실기기 확인 ①②③…** | 사람이 실제 기기에서 눈으로 판정할 목록. HANDOFF §2 안에 산다 |

## 규칙 이름

| 이름 | 무엇 |
|---|---|
| **D-1 ~ D-5** | 진단 절차 — 표식 먼저 · 재현 먼저 · 반증 실행 · 사람 말은 후보지 결론 아님 · 픽스처 범위 |
| **R1 ~ R8** (34-0 대조표) | 화면 규칙. 손잡이를 더하면 그 라운드 안에서 표를 **다시** 돌린다 |
| **원칙 a / b / d / e** | 출처는 하나 · 파생은 저장 안 함 · 미리보기가 확정본 · 선폭은 화면 고정 |
| **A-3** | 선례를 따른다. 애매하면 놓지 않되 버리지 않는다 |
| **KEY_ORDER** | 파일에 저장될 항목 목록. **새 항목을 안 적으면 조용히 저장이 안 된다** (`roundtrip43` 게이트 ②가 잡는다) |
