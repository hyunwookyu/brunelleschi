# 용어

이 저장소가 쓰는 말. 세션이 새 용어를 만들면 **여기 한 줄 더한다.**

## 시험

| 말 | 뜻 |
|---|---|
| **원장** | 잰 숫자를 적어 두는 장부(`stage0/out/*.json`). 여러 라운드에 걸쳐 값을 비교하려면 남아 있어야 한다. `LEDGER=1` 없이는 한 바이트도 안 써진다 — 기준선을 실수로 덮는 것을 막는다(#90 · #94 · #99) |
| **팔** | 앱을 대신 조작하고 재는 시험 코드. 「팔이 빨갛다」 ≠ 「앱이 틀렸다」 |
| **게이트** | 라운드를 닫으려면 통과해야 하는 조건. **반드시 숫자다** |
| **초록 / 빨강** | 통과 / 실패 |
| **스펙 / 칸** | 시험 파일 하나 / 시험 하나 |
| **e2e / 단위** | 브라우저를 열어 클릭까지 하는 시험 / 함수만 부르는 시험 |
| **전량** | 시험 전부 |
| **플레이크** | 코드가 같은데 어떤 때는 통과하고 어떤 때는 실패하는 시험 |
| **워커** | 시험을 동시에 돌리는 일꾼 수. 시간을 재는 원장은 이 값에 좌우된다 |
| **dpr1 / dpr2** | 보통 화면 / 고해상도 화면 |
| **픽스처** | 시험용으로 미리 만들어 둔 장면 |
| **무회귀** | 전에 되던 것이 그대로 된다 |
| **반증** | 일부러 망가뜨려 「내 계측이 진짜 재고 있나」를 확인하는 것 (D-3) |
| **귀속** | 이 빨강이 이번 라운드 탓인지 원래 그랬는지 가리는 것 |
| **부모 트리** | 이번 라운드 착수 전의 코드. 귀속을 가릴 때 여기서 같은 시험을 돌린다 |

**실행 셋** (web2-54가 만들었다)

```
e2e:green    병렬 · 계측 넷 제외 · dpr2는 목록만    빠른 확인
e2e:night    전량 · dpr2 전부 · 계측 포함          마감 검증
e2e:ledger   LEDGER=1 · 워커 1 · 스펙 하나씩       원장을 쓸 때만 (#99)
```

## 배포

| 말 | 뜻 |
|---|---|
| **커밋 / 해시** | 저장된 판 하나와 그 이름표 (`4eecab5`) |
| **갈래** | 본선(main)을 안 건드리고 따로 작업하는 가지 |
| **마감** | 라운드 끝내는 절차 — 전량 돌리고 · 보고 쓰고 · 배포하고 · 문서 갱신 |
| **deploy-check** | 실제 사이트가 그 커밋을 띄우는지 확인하는 스크립트. **「푸시했다」와 「배포됐다」는 다르다**(#58) |

## 문서

| 말 | 뜻 |
|---|---|
| **HANDOFF** | 「지금 무엇이 끝났고 다음이 무엇인가」의 **유일한 출처**. §2 대기열이 정본 |
| **NOTES** | 라운드별 작업 기록 |
| **PITFALLS #NN** | 실제로 저지른 실수의 번호 목록. 같은 실수를 두 번 안 하려고 |
| **DEFERRED** | 알면서 미룬 것들 |
| **DECISIONS (D-…) / assumptions (AS-…)** | 결정 / 가정 |
| **selfcheck · STALE** | 문서끼리 어긋났는지 검사하는 스크립트 · 없는 것을 가리키는 인용 |
| **착수 표** | 세션이 시작할 때 「이번에 지킬 것」을 옮겨 적는 목록 |
| **⚑** | 사람 눈이 판정해야 하는 갈림. 멈춤 조건이 아니다 — 실기기 항목으로 올리고 계속 간다 |
| **실기기 확인 ①②③…** | 사람이 실제 기기에서 눈으로 판정할 목록. HANDOFF §2 안에 산다 |

## 규칙 이름

| 이름 | 무엇 |
|---|---|
| **D-1 ~ D-5** | 진단 절차 — 표식 먼저 · 재현 먼저 · 반증 실행 · 사람 말은 후보지 결론 아님 · 픽스처 범위 |
| **R1 ~ R8** (34-0 대조표) | 화면 규칙. 손잡이를 더하면 그 라운드 안에서 표를 **다시** 돌린다 |
| **원칙 a / b / d / e** | 출처는 하나 · 파생은 저장 안 함 · 미리보기가 확정본 · 선폭은 화면 고정 |
| **A-3** | 선례를 따른다. 애매하면 놓지 않되 버리지 않는다 |
| **KEY_ORDER** | 파일에 저장될 항목 목록. **새 항목을 안 적으면 조용히 저장이 안 된다** (`roundtrip43` 게이트 ②가 잡는다) |

## 앱

| 말 | 뜻 |
|---|---|
| **리프팅** | 2D 획을 3D로 세우는 것 |
| **오스냅** | 기존 점에 커서가 물리는 것 (캐드의 그것) |
| **겹** | 트레이싱지·옐로 같은 층 |
| **자립 3D (own3)** | 획이 제 3D를 갖게 된 상태. **사건이다** — 근거를 지워도 되돌아가지 않는다 |
| **f / fSource** | 원근의 깊이 배율. **화면에 절대 안 나온다** (D-L55) |
| **분류** | 면의 갈래(외벽·내벽·슬라브 등). **두께 t · 오프셋 기준 · 우선순위 · 코어 여부**를 든다. 면은 분류를 가리키고 예외만 덮어쓴다 (web2-55) |
| **세 슬롯** | 면의 앞 · 뒤 · 테두리. **테두리는 실제 표면이고 칠할 수 있다. 단면이 아니다** |
| **접합** | 벽이 만나는 자리. 두 층 스택을 우선순위 순으로 훑어 계단 폴리라인을 낸다 (web2-56) |
| **구간 (span)** | 면 경계 «자리»마다, 그 자리의 이웃 두 경계 직선과의 교점이 끊는 범위 [lo,hi] — 한 획이 한 루프에 두 번 서면 자리마다 제 구간이다. **3D 매개변수다(화면 분율이 아니다 — 원근 단축)** · **파생이라 저장 안 한다.** 지우개가 구간 밖 조각만 닿으면 면은 무관하다(이웃 경계의 구간 조각까지 물면 그 경계가 죽어 열린다 — 알림 있음) (web2-57) |
| **이관 (carry)** | 지우개가 획을 조각으로 갈아 끼울 때, 구간을 덮는 조각의 새 id로 면 경계 참조가 넘어타는 것. 실행취소 대상(`op.edgeMoved`) (web2-57) |
| **브러시 작업대 (tunelab)** | 설정에 숨은 튜닝 실험실(web2-58) — 브러시 넷의 값·곡선 전부를 손잡이로 열고 옆 판에 바로 그어 본다. **시험 긋기 == 제품 굽기(같은 paintMark)** · 「굳힌다」= 기기 저장 |
| **커버리지 지도 (stroke buffer)** | 한 획의 도장을 **최대값**으로 모은 지도(web2-59) — 도장이 겹쳐도 안 쌓이고, 결 마스크·구멍을 곱한 뒤 불투명도로 **한 번** 얹는다. 획 «사이»만 쌓인다. 마커(band)는 예외(multiply) |
| **미리보기 획 (paintDraft)** | 그리는 중의 점렬을 커밋과 **같은 함수**(buildPaintStrokes)로 만든 획 목록(web2-59 · 런타임 · 저장 ⛔). 면 텍스처가 굽힌 판의 사본(base) 위에 같은 paintMark로 덧그린다 — 원칙 d의 코드 자리 |
| **결 마스크 · 결 사다리** | 결은 도장마다가 아니라 획의 모인 커버리지에 **한 번** 곱하는 픽셀 마스크(web2-59). 칸은 면 고정 — 칸의 자(굵기)는 2^(1/4) 사다리로 양자화해 원근 환산의 미세 차가 칸 경계를 못 밀게 한다 |
| **출발점 (START_POINTS)** | 실험실 「출발점」 단추가 얹는 도구별 값 표(web2-60) — 사람이 한 번 얹어 비교하는 값이지 세션의 최종값이 아니다. 연필·붓·마커는 mypaint 연필(CC0 값만), 색연필은 60-2 조사 값. 굳히기 전에는 세션뿐 |
| **문턱↔압력 (cpBurnish)** | 색연필 구멍 문턱이 압력에 따라 움직이는 세기(web2-60 60-2): 문턱 = 구멍 문턱 + k × (0.5 − 압력). 세게 누르면 «진해지는» 게 아니라 «구멍이 메워진다»(버니싱). 0 = 문턱 고정 |
| **속도·방향 축** | 도장마다 «원본 표본 간격 ÷ 굵기»(속도의 대리)와 «진행 각 대 촉 축»(납작한 촉)이 알파·굵기를 움직이는 손잡이 넷(web2-60 60-4). 기본 0 = 픽셀 무변 |
| **값 꺼내기 / 가져온다** | 실험실의 조정 전부를 JSON으로 밖에 내고(클립보드·textarea) 다시 얹는 길(web2-60) — 굳힌 값이 기기에만 있으면 다음 세션이 못 읽는다. 채팅에 붙이면 세션이 읽는다 |
| **BrushDef** | 브러시 하나의 값 묶음(core/brush58) — 엔진은 모드 셋(band·stamps·bristles)뿐이고 **새 브러시는 값 한 벌이지 코드가 아니다**. 기본값(51 상수) + 사람 조정(기기)의 합성 |
