## 1. 제품 정의 변경

**이전**: 완성된 스케치를 해석해 형태를 추론한다.
**이후**: 카메라를 먼저 세우고, 그 위에서 투시 작도로 3D를 직접 구축한다.

SketchUp의 선 도구와 추론 메커니즘이 사실상 같다. 유일한 차이는 카메라의 출처다 — SketchUp은 3D 앱이라 처음부터 알고, 여기서는 초반 입력이 그것을 정한다.

### 1.1 이것이 해결하는 것

지금까지 막혔던 문제들은 전부 **미지수가 관측보다 많아서** 생겼다. 알고리즘으로 해결 불가능한 종류였다.

| 문제 | 이전 상태 | 이후 |
|---|---|---|
| 2점 종횡비 | 상대폭 0.894, 사실상 미확정 | 카메라 확정 후 결정론적 |
| 꼬리 실패 20.5% | 사전 판정 불가 (기하적 서명 없음) | 추론하지 않으므로 발생하지 않음 |
| 1점 f 미결정 | unresolved | 설정값 (렌즈 슬라이더) |
| 축 뒤바뀜 28.75% | 게이지 자유도 | 카메라가 세계 좌표를 고정 |
| 비직교 52.6% 범위 밖 | 파서 한계 | 면 위 선은 복원 가능, 상당 부분 회수 |
| 매스/보이드 판별 | 별도 분류기 | 면을 직접 만드니 자동 |

**추론이 사라지고 계산만 남는다.** 커서 픽셀 하나가 3D 점 하나를 유일하게 결정한다 — 눈에서 커서로 나가는 광선과 (시작점 + t·축방향) 직선의 최근접점.

### 1.2 범위

**되는 것**
- 직교 볼륨과 실내 공간의 와이어프레임 모델링
- 면 위의 사선 (대각선, 경사 지붕, 계단 코 선)
- 벽 두께 — 평행선 두 개를 그으면 된다. 시스템이 "벽"으로 알 필요 없음
- 궤도 회전 후 다른 각도에서 계속 그리기

**안 되는 것**
- 곡선, 자유 형태
- BIM 요소 (층·창·문의 의미론)
- 정밀 치수 작업

## 3. 카메라 확정 — 제약 누산기

### 3.1 원칙

입력 방식을 고정하지 않는다. 여러 제스처가 같은 누산기로 수렴한다.
이론서 5장의 자유도 회계가 그대로 자료구조가 된다.

| 제스처 | 기여 제약 | 자유도 감소 |
|---|---|---|
| 점 찍기 | 소실점 확정 | 2 |
| 선 하나 | 소실점이 이 직선 위 | 1 |
| 선 두 개 이상 | 교점 클러스터 → 소실점 | 2 |
| 지평선 | 수평 VP들이 이 위 + 주점 y | 1 |
| 렌즈 슬라이더 | f | 1 |
| 이후 엣지 | 자기 축 VP에 투표 | 누적 |

"찾아내기"와 "정의하기"의 구분이 없다. 깊이선 두 개의 교점이 소실점이고, 점을 찍어도 소실점이다.

### 3.2 상태 표시

이론서 5.3절 표가 화면에 나온다.

```
소실점 1개  →  1점 투시 · f 자유           [렌즈 24mm]
소실점 2개  →  2점 투시 · 주점x/f 중 1자유   [주점=화면중심]
소실점 3개  →  확정
```

부족하면 무엇이 부족한지 보이고, 채우는 방법이 여럿이다.

**부분 확정 상태에서도 그릴 수 있다.** 1점에서 f가 자유여도 폭·높이는 실척으로 읽히므로(7.7절) 그 축의 선은 즉시 배치된다. 깊이만 미정이고 f가 정해지면 채워진다.

### 3.3 해 계산

| VP 개수 | 방법 | 근거 |
|---|---|---|
| 3 | 주점 = 수심, f² = \|PVᵢ\|·\|PHᵢ\| | 6.3, 6.4 |
| 2 | 지평선 → 주점 y, f² = \|PV₁\|·\|PV₂\| | 6.2 |
| 1 | 소실점 = 주점, f는 설정 | 5.3 |

과잉 결정 시 최소제곱, **잔차를 표시**한다. 오류가 아니라 정보다 — 어느 입력이 어긋났는지 알려준다.

### 3.4 유효성 검사 (실시간)

- **3점 예각 조건** (6.5절): 둔각이면 f² < 0. 물리적으로 존재하지 않는 카메라. 점을 끄는 동안 즉시 붉게 표시
- **화각** (18.4절): d < 0.5W면 90° 초과 경고, d ≥ 0.87W면 정상

### 3.5 갱신 정책

그리는 동안 엣지 투표로 카메라가 미세하게 움직이면 이미 배치된 기하가 흔들린다.

**소프트 락**: 확정 전까지 자유 갱신, 확정 후 잠금. 사용자가 명시적으로 풀면 재조정 가능하고, 그때 기하가 따라 움직이는 것은 예상된 동작이다.

### 3.6 화면 밖 소실점

2점 투시에서 흔하다. 캔버스보다 넓은 좌표계를 두고 축소 뷰에서 찍거나, 화면 가장자리 방향 핸들.
무한대는 명시적으로 표현한다 — c=0인 축 (2.2절).

### 3.7 프리셋

실내 1점 24mm / 실내 2점 35mm / 외부 2점 50mm / 외부 3점 앙각.
기본값으로 두고 필요할 때 조정. 세션 시작 마찰을 없앤다.

### 3.8 투시 그리드

카메라가 정해지면 캔버스에 옅은 지면 격자와 축 가이드를 깐다.
사용자가 그리기 전에 축 방향을 보므로 스냅이 예측 가능해진다.
건축가가 원래 구축선을 먼저 긋고 그리는 방식과 같다.

## 4. 추론 엔진

SketchUp의 inference에 해당한다. 핵심 구성요소.

### 4.1 방향 추론

획의 방향을 다음 중 하나로 분류한다.

- VP1 / VP2 / VP3 방향
- 화면평행 (c=0, 축소 없음)
- 면 위 사선 — 어떤 VP도 향하지 않으나 이미 정의된 면 안에 있음
- 미분류

**분류는 점-직선 거리로 한다.** 선을 연장해 소실점을 지나는지 검사. 각도 추정보다 강건하다 — 끝점 오차가 방향에 미치는 영향이 작고, 클래스가 서로 멀다.

**제약 재적합**: 분류된 선을 정확히 그 VP를 지나도록 다시 적합한다. 자유도가 2에서 1로 줄고 손떨림이 제거된다. 직교 스냅이 평면에서 하던 일의 투시 판.

### 4.2 위치 추론

방향만으로는 깊이가 정해지지 않는다. 앵커 체인이 필요하다.

1. **씨앗**: 지면 접촉점. 첫 선의 시작점을 Z=0으로 둔다
2. **전파**: 그 점에서 알려진 방향으로 광선-직선 최근접점
3. **교차**: 기존 엣지와 만나는 지점이 새 앵커
4. 반복

**연결된 것만 배치된다.** 떠 있는 획은 깊이 미결정이며, 가장 가까운 기존 기하에 붙이거나 사용자에게 지정을 요구한다.

### 4.3 스냅 대상

- 기존 엣지의 끝점 / 중점
- 엣지 위의 임의 점
- 면 위
- 축 방향 (VP 4종)
- 평행 / 수직 (기존 엣지 기준)

### 4.4 실시간 피드백

**이것이 없으면 사용자가 왜 그렇게 됐는지 모른다.** SketchUp이 축 색과 툴팁으로 하는 것.

- 획을 놓기 전에 스냅될 방향을 미리 표시
- 축별 색상 (VP1/VP2/VP3/화면평행)
- 스냅 대상 하이라이트
- 추론 근거 툴팁 ("VP2 방향", "기존 엣지 끝점")

## 5. 기하 구축

### 5.1 자료구조

```
Vertex  { id, position: Vec3, provenance }
Edge    { id, v0, v1, direction: VP1|VP2|VP3|screen|free }
Face    { id, edges[], normal, plane }
Camera  { vps[], principal, f, locked }
```

IR을 대체한다. 루트 필드 제한(§13)은 유지하되 구조가 단순해진다.

### 5.2 면 생성

닫힌 동일평면 루프가 만들어지는 순간 메쉬를 채운다.

- 엣지 그래프에서 최소 순환 탐색
- 공면성 검사 (허용 오차 필요)
- 경계 조건: T자 접합, 근사 공면, 자기교차

**시간이 예상보다 걸릴 수 있는 곳이다.** 알고리즘은 알려져 있으나 경계 조건이 성가시다.

### 5.3 편집

실시간 편집기이므로 필요하다. 지금 없는 개념.

- 되돌리기 / 다시하기
- 엣지 삭제
- 정점 이동 (연결된 엣지 따라감)
- 카메라 재조정 (소프트 락 해제 시)

## 6. 획 → 엣지 매핑

### 6.1 유일한 미측정 항목

프리핸드가 마우스 드래그만큼 깔끔하지 않다. 덧그림, 분절, 지나침.

**첫 단계에서 측정한다.** 나머지를 만들기 전에 판단이 서야 한다.

- 한 획이 한 엣지로 매핑되는 비율
- 덧그림 병합 정확도
- 획 분절 오류율 (한 획이 여러 엣지여야 하는 경우)

### 6.2 처리

- PaleoSketch로 직선/곡선 판별
- 덧그림 병합 (같은 위치 재방문)
- 지나침 절단 (교차점 기준)
- 한 획이 꺾이면 분절

## 7. 작업 순서

Playwright. 카메라 확정 → 그리기 → 면 생성 → 회전 → 계속 그리기.
지연 측정. 스크린샷 회귀.

## 9. 위험

**획 → 엣지 매핑.** 유일하게 원리적 미확인 항목. W-0에서 먼저 잰다.

**스냅 감각.** 수학이 아니라 감각의 문제다. tolerance를 얼마로 둘지는 그려봐야 정해진다.
다만 실패 모드가 온건하다 — 어긋나면 다시 그으면 되고, 이전처럼 "형태가 통째로 틀린 채 나온다"가 아니다.

**면 생성 경계 조건.** T자 접합, 근사 공면, 자기교차. 시간이 걸릴 수 있다.

**비교 대상이 명확하다는 이점.** SketchUp이 존재하므로 조작감의 목표가 있고, 사용자도 기대치를 안다. 이전에는 "잘 되는 것"의 기준이 없었다.

## 10. assumptions 이관

폐기 항목에 딸린 assumptions를 정리한다.

**무효화** (해당 코드가 사라짐)
- 사전분포 관련 전 항목
- 2점 종횡비 미확정 관련
