# 사슬 규칙 — web2-54 → 55 → 56

한 세션(Fable)에서 이어 간다. 각 라운드를 **완주·배포**하고 `web2/HANDOFF.md` §2를
갱신한 뒤 다음으로 넘어간다. **갈래를 먼저 딴다** — 52가 main 직행을 자백했다.

## 이 사슬의 성격 — **54가 나머지를 싸게 만든다**

**§1(시험 시간)을 제일 먼저 끝내라.** 지금 전량 e2e가 워커 하나로 45분을 돈다.
55·56은 큰 라운드라 그것을 여러 번 돌려야 한다 — **54의 §1이 안 끝나면 이 사슬이
시험을 기다리는 데 하루를 쓴다.**

그 뒤의 순서는 **의존이지 편의가 아니다**:

```
55는 54에 안 기댄다        ─ 다만 54의 새 e2e 명령을 쓴다
56은 55에 «기댄다»          ─ 분류가 t·우선순위·코어를 들지 않으면 병합 걸음이 훑을 스택이 없다
```

그러므로 **55가 안 서면 56에 착수하지 마라.** 순서를 바꾸지도 마라.

## 멈춤 조건 — 셋 중 하나면 멈추고 보고한 뒤 대기하라

```
① 측정이 지시문의 전제와 어긋난다
② 게이트가 통과 못 한다
③ 지시문에 없는 갈림이 나온다
```

지시문의 전제가 틀렸다고 판단되면 **고쳐서 진행하지 말고 멈춰라.**

**⚑ 표시는 멈춤 조건이 아니다.** 사람 눈이 필요한 판정이라는 뜻이고,
**실기기 확인 항목으로 올린 뒤 다음 라운드로 계속 간다.** 답을 기다리며 세션을 붙들지 마라.

## 이 사슬만의 멈춤 조건 하나 더

**54 §1의 게이트 2가 안 서면 사슬 전체를 멈춰라.**

> 「병렬 초록 실행과 워커 1 전량의 **통과 집합이 동일하다**」

이것이 안 서면 **빨라진 것이 아니라 덜 잰 것**이고, 그 상태로 55·56을 돌리면
두 큰 라운드가 **무엇이 초록인지 모르는 채로** 배포된다. #89를 닫는 게 아니라 다시 여는 것이다.

⚠ 시간에 쫓기면 여기를 무를 유혹이 생긴다. **무르지 마라 — 무를 바에는 §1을 통째로
되돌리고 옛 명령으로 55·56을 가라.** 느린 것이 모르는 것보다 낫다.

## 사람이 이미 닫은 판정 — 다시 열지 마라

```

㉓ 브러시 자국의 질  「쓸만하다」            → 브러시 엔진 재수술 없음

내보내기            보류 — 53은 파일만 있고 착수 금지(조건: 56 완주)
```
