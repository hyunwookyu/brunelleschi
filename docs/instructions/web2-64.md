# §1 결함 넷 — 먼저 고친다

## 64-1 ⛔ **브러시를 바꾸면 이미 그린 것이 바뀐다** (저장 결함)

사람 보고: 「브러시 고르개에서 하나 선택해서 그린 다음에 다른 브러시 고르려고 선택하면
**기존에 그린 것들도 새로 고른 브러시 형태로 바뀐다.**」

**원인**: 획이 저장하는 것은 `paint.i` — **«슬롯»**(0 붓 · 1 마커 · 2 색연필 · 3 연필)뿐이다.
브러시는 슬롯에 «지금» 물려 있는 것이라, 슬롯의 브러시를 바꾸면 그 슬롯의 **옛 획이 전부
다시 구워진다.** 원칙 a(출처는 하나) 위반이고, 그림을 잃는 결함이다.

**고치는 법 — 슬롯의 뜻을 바꾼다.**

```
지금   획 → 슬롯     · 슬롯 → 브러시(가변)     ⛔ 옛 획이 따라 변한다
뒤     획 → «브러시 id»                        슬롯은 «빠른 자리»일 뿐이다
```

- 획에 **브러시 id**를 저장한다. `KEY_ORDER`에 등재하라 — `roundtrip43` 게이트 ②가 지킨다
- **옛 문서 이주**: `paint.i` → 그 슬롯의 «지금 기본 브러시 id». 조용히 하지 말고 한 줄로 알려라
- 슬롯(붓·마커·색연필·연필)은 **없애지 않는다.** 뜻만 바뀐다 —
  「이 슬롯 = 이 브러시」가 아니라 **「이 자리에 이 브러시를 놔뒀다」**(즐겨찾기)

**D-2**: 착수 전에 재현하라 — 브러시 A로 긋고, 슬롯의 브러시를 B로 바꾸고, 옛 획의 픽셀이
바뀌는지 값으로.

## 64-2 색연필이 흑연 연필에 매여 있다

`cp = ramon/B-pencil`이다. 그것은 색연필이 아니라 **연필**이다.
그래서 63의 비트맵 팁으로 넷이 갈릴 때 **cp만 62와 거의 같았다**(사진에서 확인).

196개에서 색연필에 맞는 것을 다시 고르고, 없으면 **색연필의 성질**로 만들어라 —
안료가 종이 봉우리에만 얹히고(구멍), 압력이 알파가 아니라 **문턱**을 내리고(버니싱),
한 번 지나가면 옅다. `docs/PAINT-TIERS.md`와 60-2가 그 문면이다.

## 64-3 젖은·블렌더 브러시가 «판정이 안 됐다»

`tanda/*-only-water` · `oil-*-clean` · `oil-mop` · `water-01/02/05/06` ·
`watercolor-02-water` 등 열둘 안팎이 62 카탈로그에서 **전부 빈칸**이다.

**결함이 아니다** — `opaque: 0`이라 «있는 색을 문지르는» 브러시이고, 빈 캔버스에서는
아무것도 안 나오는 것이 맞다. **문제는 아무도 확인을 안 했다는 것이다.**

**색을 먼저 칠한 판 위에 그은 카탈로그를 한 장 더 내라** — `64-catalog-wet.png`.
거기서 안 도는 것이 있으면 그것이 진짜 결함이다.

## 64-4 팁이 든 자국이 절차보다 옅다

63이 물은 것(평균 .0935 vs .1088). 팁 알파의 정규화로 보인다.
**팁이 있든 없든 같은 설정이면 같은 농도**가 되도록 맞추고 값으로 보여라.
⚠ 자국의 «성격»을 바꾸지 마라 — 농도만 맞춘다.

## 64-5 `watercolor-02-paint`가 거의 안 보인다

수채의 대표 프리셋이 흐릿하다. 프리셋 값 문제인지 우리 이식 문제인지 가려라
(같은 `.myb`의 설정 65개가 전부 사상됐는지 먼저 본다 — 62의 게이트 ⑥).

# §2 칠 패널 — 구조를 평평하게

사람 지적: 「**버튼·도구의 트리 구조가 복잡하고 직관적이지 않다.** 첫 버튼은 붓이고, 그 안에
또 붓·마커·색연필·브러시 고르개·색상·색상 프리셋… **상용툴의 UI 구조를 그대로 가져와도
될 텐데.** 브러시 형태를 찾아가는 과정이 너무 길다. **자꾸 뭘 펼쳐야 하는가?**
선택된 브러시는 항상 떠 있고, 그걸 누르면 다른 걸 선택할 수 있다.
포토샵을 보면 한 화면에 브러시 형태·색상·투명도·크기를 한 번에 설정한다.
**연필 경도가 항상 표시돼 있듯 이 정보들도 패널 한쪽을 차지하며 항상 표시가 낫지 않나.**」

## 원칙 — R8의 정정을 이 라운드가 적는다

R8은 「항상 보이는 것은 잠깐 얹히는 것보다 약하다」이고, 그래서 지금까지 칠 설정을 통에
숨겼다. **그 적용이 틀렸다.**

> **칠 도구를 든 «동안»에는 칠 설정이 곧 그 일이다. 그때는 항상 보인다.**
> 작도 중에는 없다. R8은 «경쟁하는 것들» 사이의 규칙이지 «지금 하는 일»에는 안 걸린다.

**34-0 대조표에 이 정정을 값으로 적어라.**

## 만들 것 — 칠 패널

칠 도구를 들면 화면 한쪽에 **항상** 뜬다. 놓으면 사라진다.

```
┌──────────────────────┐
│ [지금 브러시의 자국 견본] │ ← 누르면 «브러시 목록»이 얹힌다. 그것뿐이다
│  brush 이름             │
├──────────────────────┤
│ 크기     ──●─────  24 │ ← 값이 숫자로 같이 보인다
│ 불투명   ─────●──  0.7│
├──────────────────────┤
│ [색 원]                │ ← 누르면 색상 휠이 얹힌다
│  최근 색 대여섯          │
├──────────────────────┤
│ [즐겨찾기 4~6]          │ ← 옛 «도구 넷»의 자리. 브러시 바로가기
└──────────────────────┘
```

**규칙 넷**

```
① 지금 브러시는 «항상» 보인다 — 자국 견본으로. 이름만으로는 안 된다
② 펼치는 것은 둘뿐이다 — «브러시 목록»과 «색상 휠». 그 둘도 한 단계다
③ 색상 프리셋을 없앤다 (사람 지시: 「필요없다」)
④ 이름을 고친다 — 「브러시 고르개」 → **「브러시」**
```

⛳ **게이트로 잴 것**: **칠의 어떤 설정에도 «두 번 펼쳐서» 닿지 않는다.**
크기·불투명도·색·브러시 — 전부 0단계(항상 보임) 또는 1단계(한 번 누름)다.
지금은 2단계다(붓 → 통 → 고르개).

## 즐겨찾기 — 슬롯의 새 이름

옛 도구 넷의 자리다. 4~6칸. 각 칸에 브러시를 놔둔다. 길게 누르면 지금 브러시로 바꾼다.
**64-1에서 획이 브러시 id를 저장하게 되므로, 칸의 브러시를 바꿔도 옛 획은 안 변한다.**

# §3 면 — 탭으로 고른다

사람이 정했다: 「**면은 탭으로 고르면 된다.**」

- **칠 도구를 든 상태에서 면을 탭하면 그 면이 골라진다.** 꾹 누름이 아니다
- 여럿 고르기는 54가 넣은 그대로 — 탭으로 더한다. 빈 곳 탭이면 풀린다
- ⚠ 탭과 «짧은 획»이 갈려야 한다. 시간이 아니라 **움직인 거리**로 갈라라(#93 — 몸짓을
  시간으로 읽으면 기기가 느려질 때 다른 몸짓이 된다). 문턱을 값으로 정하고 원장에 남겨라
- **정면 왕복**은 54가 넣은 그대로 산다

⚠ **작도 중에는 탭이 면을 고르면 안 된다** — 칠 도구를 들었을 때만이다.

# §4 정리 — 새 칠과 «관계없는 것»을 지운다

사람이 물었다: 「**기존의 칠 도구나 프리셋, 새로 추가한 칠 도구랑 관계없는 건 삭제하는
내용도 들어있나?**」 — 안 들어 있었다. 이 절이 그것이다.

라운드가 열넷 동안 «더하기»만 했다. 엔진을 두 번 갈아치웠으니 죽은 무게가 반드시 있다.
**저장소에서 확인한 것을 값으로 적는다**(추측 아님).

## 64-7 색상 프리셋 · 견본 줄
