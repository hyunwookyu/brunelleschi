# 사슬 규칙 — web2-50 → 51 → 52

한 세션(Fable)에서 이어 간다. 각 라운드를 완주·마감하고 `web2/HANDOFF.md`를 갱신한 뒤
다음으로 넘어간다.

**착수 전에 49의 완주 보고를 읽어라.** 49가 만든 절차적 무늬 생성기가 52의 재료가 되고,
49가 남긴 갈래(벽돌 줄눈의 원점·방향 등)가 52에서 정해진다.

## 멈춤 조건 — 셋 중 하나면 멈추고 보고한 뒤 대기하라

```
① 측정이 지시문의 전제와 어긋난다
② 게이트가 통과 못 한다
③ 지시문에 없는 갈림이 나온다
```

지시문의 전제가 틀렸다고 판단되면 **고쳐서 진행하지 말고 멈춰라.**

**⚑ 표시는 멈춤 조건이 아니다.** 그건 사람 눈이 필요한 판정이라는 뜻이고,
**실기기 확인 항목으로 올린 뒤 다음 라운드로 계속 간다.** 답을 기다리며 세션을 붙들지 마라.

## 이 사슬의 성격

**50이 전부다.** 51·52는 그 위에 얹는 것이고, 50이 안 서면 브러시를 아무리 손봐도 지금과 같다.
50에서 손을 넓히지 마라 — 구조만 바꾸고 자국은 그대로 옮긴다.

## 모든 라운드에 적용

- CLAUDE.md §D · 게이트를 실제로 실행해 수치와 함께 보고
- 임계를 무르거나 픽스처를 쉽게 만들지 마라 · 새 임계는 `web/test/constants.ts`
- `Math.random` 금지 (씨앗은 `rng32`) · `LEDGER=1` 없이 원장 쓰기 금지
- 전량 e2e는 손으로 — 「Pages 초록 = 전량」 아님 (#89)
- 마감은 `deploy-check.mjs` · 대기에는 상한 (#81) ·
  마감 보고에 **「도는 백그라운드 없음」**을 값으로
- **라운드를 백그라운드 에이전트에 통째로 위임하지 마라** — 두 번 잃었다.
  하위 에이전트는 라운드 안의 자기 완결 항목에만 쓰고, 마감과 갈래 판단은 세션이 직접 한다
- **손잡이를 추가하면 34-0 대조표(R1~R8)를 그 라운드 안에서 다시 돌려라** —
  한 번 쓸고 끝나는 검사는 반드시 샌다 (지금까지 네 번 샜다)
