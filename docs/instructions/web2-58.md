# web2-58 — 자국

> **Fable.** 이 라운드의 값은 **사람이 당겨서 정한다.** 세션이 정하지 마라.

## 왜 — 사람 판정 (2026-09-03)

> 「**칠하기 관련은 하나도 개선된 게 없네? 이전과 똑같은데?**」

그럴 만하다. **51이 사람의 요구 둘을 정반대로 못 박았고, 둘 다 지시문을 쓴 쪽의 잘못이다.**
이 라운드는 그 둘을 되돌리는 것부터 시작한다.

```
51 문면                                사람이 실제로 요구한 것
「슬라이더를 만들지 마라」               「칠하기 도구니 이건 슬라이더로 크기를 조절해야
                                        하며, 최대치 40은 너무 작다. 마카는 100, 붓은
                                        500, 색연필은 50, 연필은 50」
「텍스처 이미지를 브러시 팁으로          (근거는 알파 합성 사고였다. 50이 합성을 2D 캔버스
 쓰지 마라 — 결은 계산에서 나와야 한다」   안으로 옮긴 뒤로 그 근거가 사라졌다)
```

51은 「자국의 질」 라운드였는데 그 둘에 막혀 있었고, 그 뒤 브러시 라운드는 한 번도
안 왔다(53이 내보내기가 되면서 밀렸다). **그래서 실제로 아무것도 안 바뀐 것이 맞다.**

## 58-1 — 크기는 슬라이더다 (51 문면 철회)

**R1을 다시 읽어라.** R1은 「**진짜 도구가 이산인 곳**에 연속 조절을 두지 마라」다.
연필 등급(2H·HB·2B)과 펜 촉(0.18·0.25·0.35)은 실제로 이산이라 트레이가 맞다.
**칠 도구의 크기는 이산이 아니다** — 실제 붓도 마커도 연속이다. 51이 R1을 잘못 댔다.

```
마커   최대 100
붓     최대 500
색연필 최대  50
연필   최대  50
```

**34-0 대조표를 이 라운드 안에서 다시 돌려라** — R1의 적용 범위가 바뀐다.
그 정정(「R1은 작도 도구에만」)을 표에 값으로 적어라.

## 58-2 — 텍스처 팁 금지를 푼다 (51 문면 철회)

금지의 근거는 「알파가 계산에서 나오면 프리멀티플라이드 문제가 원천적으로 안 생긴다」였다.
**50이 칠을 2D 캔버스 안으로 옮겼으므로 그 문제 자체가 없어졌다.**

스탬프 이미지와 그레인 이미지를 쓸 수 있다. **다만 절차적 생성을 버리지 마라** —
49·51이 만든 생성기는 살아 있고, 텍스처는 «더할 수 있는 수단»이지 대체가 아니다.

## 58-3 — 엔진은 하나, 브러시는 데이터

지금은 브러시 넷이 각자 코드를 갖고 있을 것이다(51이 그렇게 넣었다). 그래서 넷을
따로 고쳐야 하고, 하나를 고치면 셋이 안 따라온다. 표준 구조로 바꾼다.

```
입력      압력 · 속도 · 방향 · 획 진행도 · 난수 · (기울기)
   ↓
매핑 곡선  입력마다 곡선 하나
   ↓
설정      반지름 · 불투명도 · 경도 · 간격 · 산포 · 회전 · 번짐 · 그레인
```

**브러시 넷은 이 표의 «값 묶음»일 뿐이다.** 새 브러시는 값 한 벌이지 코드가 아니다.

## 58-4 — 끝점 뭉침 (사람이 지적한 결함)

> 「마커나 붓은 **획의 시작과 끝에서 원형 강조**가 생기는데 매우 거슬린다」

원인은 거의 확실히 **간격이 시간 기반**이라서다. 손이 느려지는 시작·끝에서 스탬프가
같은 자리에 여러 번 찍힌다.

**간격을 «거리» 기반으로 바꿔라** — 반지름의 몇 %마다 한 번. 이것이 표준 해법이다.

**D-2**: 착수 전에 지금 상태를 재현하라 — 획 하나의 시작·중간·끝에서 **단위 길이당
찍힌 스탬프 수**를 값으로. 시작·끝이 중간보다 많으면 시간 기반이 맞다.

## 58-5 — 튜닝 실험실 ← **이 라운드의 중심**

**값을 말로 주고받는 것을 그만둔다.** 두 번 실패했다(51·52). 사람은 연필 선이 어떤지
알지만 그것을 매개변수로 옮겨 적을 수는 없다.

**만들 것**: 한 화면 안에서
```
· 브러시 넷 중 하나를 고른다
· 위 58-3의 설정과 매핑 곡선을 «전부» 손잡이로 연다
· 옆에서 바로 그어 본다 — 같은 화면에서 즉시 보인다
· 마음에 들면 「이 값으로 굳힌다」
```

**설정에 숨겨 둔다** — 평소 화면에 나오면 안 된다(R8 · 이건 도구가 아니라 작업대다).

**세션의 일은 값을 정하는 것이 아니라 «사람이 당긴 값을 정확히 굽는 것»이다.**
초기값은 **mypaint-brushes(CC0 — 의무 없음)**의 연필·목탄 값을 출발점으로 읽어라.
⚠ **libmypaint(ISC)나 다른 코드를 가져오지 마라** — 값만 참고한다.
⚠ **Krita는 GPL이다. 절대 보지 마라.**

## ⚑ 사람이 판정한다 — 그리고 이번엔 마감 조건이다

51은 「답을 기다리며 세션을 붙들지 마라」로 갔고, 그래서 답이 안 온 채 두 라운드가 지나갔다.

**이번엔 다르다.** 튜닝 실험실이 서면 **거기서 멈추고 보고하라.** 사람이 값을 당긴 뒤에
그 값을 굳히는 것이 이 라운드의 마지막 절이다. 실험실 없이 값을 정해서 마치지 마라.

## 게이트

- **크기 슬라이더**: 도구별 최대가 값대로 · 슬라이더 값 == 그어진 자국의 실제 굵기(픽셀)
- **끝점 뭉침**: 단위 길이당 스탬프 수가 시작·중간·끝에서 **±10% 안** (58-4의 D-2 값과 대조)
- **브러시가 실제로 다르다**: 넷을 같은 압력·같은 속도로 그어 **자국의 통계가 갈린다**
  (농도 분포 · 가장자리 거칠기 · 덮임률). 「붓이 흑연톤」·「색연필이 붓처럼」이
  값으로 갈리는지 본다
- **엔진 하나**: 설정 하나를 바꾸면 그것을 쓰는 브러시 «전부»가 따라 바뀐다(반증 포함)
- **실험실**: 손잡이 전수가 실제로 자국을 바꾼다 · 「굳힌다」가 값을 문서가 아니라
  기기에 남긴다(52의 프리셋 자리)
- 50의 여섯 게이트 무회귀 · 55의 칠 생존 · 56의 접합 무회귀
- 성능: 브러시가 는 뒤 면 20개 장면의 프레임
