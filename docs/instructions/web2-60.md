# web2-60 — 자국의 질

> **Fable 5.1.** 59가 뼈대를 세운 뒤에 온다. **여기서 사람이 눈으로 판정한다.**

## 왜

59는 「뭉치지 않는다」까지다. 이 라운드가 **「연필이 연필로 보이는가」**를 정한다.

목표는 사람이 말한 그대로다 — **Feather 3D의 자국 수준.**

## ⚠ 조사가 전제를 뒤집었다 — **먼저 읽어라**

**착수 전에 `docs/REFERENCE-FEATHER.md`를 통째로 읽어라.** 요지 셋.

### ㉠ **Feather에는 「칠하기」가 없다**

사람이 「칠하기가 Feather 수준이 되어야 한다」고 했지만, 조사 결과 **Feather는 칠하기를
아예 안 한다** — 채우기(fill)가 없고(가장 많이 요청받는 미구현 기능 · 2.0 예정),
브러시 텍스처도 없고, 레이어·블렌드·스머지도 없다.

**그러므로 참조를 가른다.**

```
선(작도 획)의 질  → Feather.  3D 메쉬 리본. 원리가 논문으로 공개돼 있다 (별도 라운드)
칠의 질           → 프로크리에이트.  ← **이 라운드가 여기다**
```

⚠ 「Feather처럼 칠하자」로 가면 참조할 것이 없는 곳을 참조하게 된다.

### ㉡ **Feather의 브러시는 손잡이가 «넷»뿐이다**

공식 문서 확인 — 종류·색·크기·불투명도. flow도 jitter도 taper도 streamline도 없다.
**그것으로 애플 디자인 어워드를 받았다.**

**우리는 손잡이가 23개인데 자국이 더 나쁘다.**
→ **품질은 손잡이 수에 없다.** 그들의 획은 도장이 아니라 메쉬다 — 도장이 없으니
도장 티가 날 수가 없다. 우리 칠은 래스터가 맞다(프로크리에이트도 래스터다).
**그러니 이 라운드의 답은 «축을 더 여는 것»이 아니라 «있는 축을 제대로 만드는 것»이다.**

### ㉢ Feather 1.x는 **웹앱이었고 그것을 버렸다**

네이티브 1.0의 헤드라인이 「최대 20배 빠름」이고, 2.0은 Metal 4 전면 재작성이다.
앱스토어 4.1/5의 최다 불만이 **「둔하다·지연된다」**이다.

브라우저에서 그 수준이 나온다는 증거이면서, **그들이 웹에서 진 자리가 어디인지**도 말한다.
지연은 59-4가 첫 삽을 뜬다.

**쓸 수 있는 것 / 쓰면 안 되는 것** (라이선스 전부 원문 확인)

```
쓸 수 있다
  perfect-freehand  MIT · 112KB · 무의존 · 획을 «닫힌 외곽 폴리곤 하나»로 낸다
                    → 겹침이 원천적으로 없다. 펜·마커·잉크에 완벽
                    ⚠ 연필·색연필에는 부적합 — 내부가 균일해서 결이 안 생긴다
  p5.brush          MIT · 활발(2026-08) · **이미 우리 의존성이다**
                    v2부터 p5 없이 standalone · 이미 스트로크 버퍼를 쓴다(glMask)
                    팁 다섯(이미지 팁 포함) · 브러시 11(cpencil 포함)
                    ⚠ 압력이 «획을 따라가는 프로필»이지 실시간 스타일러스가 아니다
                    → **구조를 베끼되 라이브러리로 쓰지는 마라**
  mypaint-brushes   CC0 — 의무 없음. 값을 그대로 실어도 된다
  libmypaint        ISC — 안전하지만 WASM 빌드가 죽었다(2015 asm.js). 값과 모델만 참고
  google/ink        Apache-2.0 · 메쉬 기반 · Jetpack Ink의 핵심 · ink-wasm이 웹 빌드 실증
                    ⚠ 브러시가 marker·pressure_pen·highlighter 셋뿐 — 연필이 없다
  spectral.js       MIT — 안료 혼색(파랑+노랑=초록)이 필요해지면

⛔ 금지
  mixbox            CC BY-NC — 유료 앱 불가
  tldraw            사유 라이선스
  Krita·GIMP·MyPaint 앱  GPL — 기법은 읽되 코드는 절대 가져오지 마라
```

## 60-1 — 도장이 원으로 보이지 않게 (59의 ①②③)

**실험실에 이미 축이 있다**(58이 넣었다 — `hardness`·`scatter`).
59가 뼈대를 고쳤으므로 이제 값이 실제로 먹는다.

조사가 낸 출발점 — **libmypaint `classic/pencil`의 실제 값이다**:

```
dabs_per_actual_radius 4.0   → 지름의 12.5% 간격 (지금 30%)
hardness               0.1   (지금 1.0)
offset_by_random       0.5   → 반지름의 절반만큼 흔든다 (지금 0)
opaque                 0.7
```

**이 셋이 «둥근 도장»을 안 보이게 만드는 전부다.** 팁 모양을 바꾸는 것보다 이게 먼저다.

⚠ **값을 세션이 확정하지 마라.** 실험실에 「mypaint 출발점」이 이미 있다 —
그 자리에 이 값들을 얹고, **사람이 당겨서 정한다.**

## 60-2 — 색연필 (사람이 특히 지적했다)

「특히 색연필」이라고 했다. 색연필이 제일 나쁜 데는 이유가 있다.

조사 결론, 중요도 순:

```
1  «구멍»이 있어야 한다
   안료는 종이의 «봉우리»에만 얹힌다. 완전 버니싱 전까지 색연필 자국에는
   반드시 빈 칸이 있고, 그 사이로 보이는 종이 흰색이 «색연필로 보이게» 만든다
   → 지금도 구멍을 뚫고 있다(cpSkipTh). 문제는 그 다음이다

2  압력이 «알파»가 아니라 «문턱»을 움직여야 한다      ← 여기가 80%다
   지금:  커버리지 = 알파 × 결
   맞다:  커버리지 = f(결, 문턱(압력))
          약한 압력 → 문턱이 높다 → 봉우리만 닿는다 (구멍이 많다)
          강한 압력 → 문턱이 내려간다 → 골이 메워진다 (버니싱)
   즉 세게 누르면 «진해지는» 게 아니라 «구멍이 메워진다»

3  한 번 지나가면 옅어야 한다
   색은 여러 번 지나가면서 온다. 도장 알파가 0.1보다 훨씬 아래여야 한다
   결이 «면 고정»이면(59-3) 두 번째 획이 다른 봉우리에 얹힌다 — 그게 층이 쌓이는 기제다

4  팁이 살짝 납작하고 천천히 돈다
   닳은 심은 타원이고, 그 장축은 «손»을 따라가지 «획»을 따라가지 않는다
   → 회전을 'natural'로 두면 서예가 된다. 고정하거나 아주 천천히 변하게

5  기울기 → 폭과 구멍
   눕히면 넓고 옅고 구멍이 훨씬 많아진다(심의 옆면이 봉우리 위를 스친다)
```

## 60-3 — 잉크 경로 (펜·마커)

**펜과 마커는 도장으로 그릴 이유가 없다.** `perfect-freehand`(MIT · 112KB)가
획을 닫힌 폴리곤 하나로 내고, 그러면 겹침 문제가 «없다».

이것이 구글 Ink가 나눈 것과 같은 갈래다 — 단단한 획은 외곽선 렌더러,
질감 있는 획은 메쉬/도장 렌더러.

⚠ 마커의 「겹치면 진해진다」(46)는 폴리곤 하나를 multiply로 얹으면 그대로 산다.

## 60-4 — 실험실을 넓힌다

⛳ **Feather의 「Stable Stroke」에서 가져올 것 하나** (REFERENCE §3):
부드럽게 하기 슬라이더 옆, **그 패널 «안»에 낙서판이 있다** — 값을 바꾸면서 거기 바로
그어 본다. 작품에 시험 획을 안 그어도 된다. **보이지 않는 값을 그림으로 만드는 것**이고
이 앱에서 가장 잘 만든 작은 것이다. 우리 작업대가 같은 생각이니 **그 패턴을 유지하고,
값 옆에 붙여라**(따로 떨어진 시험 판이 아니라).

58이 물어 둔 것: **없는 축 다섯**(속도·방향·기울기 · 회전·번짐).
사람의 순위를 받아 그 순서로 연다. 받지 못했으면 **속도 → 방향** 순이다
(선을 쫙 그을 때 시작은 느리고 중간은 빠르다 — 연필과 붓에서 그게 자국에 그대로 나온다).

그리고 **값을 밖으로 꺼내는 길**을 넣어라 — 굳힌 값이 기기에만 있으면 다음 세션이 못 읽는다.

## 게이트

- **둥근 도장이 안 보인다**: 획 하나의 «가장자리를 가로지르는 알파 프로파일»에서
  주기적 파형이 안 잡힌다(FFT 아니어도 좋다 — 도장 간격 주기의 진폭을 값으로)
- **색연필에 구멍이 있다**: 약한 압력에서 «빈 픽셀의 몫»을 값으로. 압력을 올리면 그 몫이 준다.
  **알파가 아니라 몫이 움직이는 것이 이 절의 판정이다**(D-3: 문턱을 고정하면 몫이 안 움직인다)
- **층이 쌓인다**: 같은 자리를 세 번 칠하면 «다른 봉우리»가 채워진다(픽셀 상관이 1이 아니다)
- **잉크 경로**: 펜·마커 획이 자기 자신과 교차해도 교차점이 안 진해진다(마커는 예외 — 진해진다)
- **넷이 갈린다**: 같은 압력·속도로 넷을 긋고 자국의 통계가 갈린다
  (알파 분포 · 가장자리 거칠기 · 빈 픽셀 몫). 「붓이 흑연톤」·「색연필이 붓처럼」이 값으로 갈린다
- 59의 게이트 전부 무회귀 · 50·55·56 무회귀
- 성능
