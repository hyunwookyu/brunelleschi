# web2-45 — 면: 찾고, 가르고, 칠한다

> **Fable.** 사슬 규칙은 `CHAIN.md`. 44가 끝난 뒤에 온다 (칠할 면을 잡아야 한다).

## 왜 이 셋이 한 라운드인가

```
면 찾기 품질  →  분류  →  칠하기
```

**지금 면 찾기가 무엇을 놓치고 무엇을 과하게 잡는지 아무도 모른다.** 면이 비어 있어서
안 보이기 때문이다. 칠하면 즉시 드러난다 — 그래서 **칠하기는 표현이면서 동시에 검사 도구**다.
나눠 돌면 검증만 세 번 늘고 사슬의 값은 안 난다.

## 45-1 면 찾기 품질 — 먼저 재라 (D-2)

고치기 전에 **지금 무엇이 나오는지** 재라. 실제 작도에 가까운 장면들에서:

- 찾아야 할 닫힌 영역 중 몇을 찾는가 (놓침)
- 찾지 말아야 할 것을 몇을 찾는가 (과잉)
- 구멍(개구부)이 있는 면이 제대로 나오는가 — web2-24에서 「기본은 구멍, 채워야 할 때
  골라서 채운다」로 정한 그것
- **깊이 정렬** — 면이 겹칠 때 무엇이 앞인가. 지금은 비어 있어 안 보이지만 칠하면 바로 드러난다

이 수치가 이 라운드의 기준선이고, 아래 전부가 그 위에 선다.

## 45-2 분류 — 법선만 본다

```
법선이 수직   →  슬라브 (바닥 · 천장)
법선이 수평   →  벽
기울어짐      →  지붕 · 경사
```

**두께를 추론하지 마라.** 예전에 「단일 평면으로 그렸는지 두께로 그렸는지 모른다」가
문제였는데, **늘 단일 평면으로 그리고 두께는 나중에 오프셋으로 준다**로 정해졌다.
추론할 것이 없어졌다. (그리는 동안 두께를 신경 쓰면 스케치가 아니다. 두께는 관찰이 아니라
결정이고, 결정은 나중에 한다.)

**외벽/내벽도 지금은 하지 마라.** 「어느 쪽이 안인가」는 닫힌 부피 판정이 필요해 신뢰도가
방향 판정과 전혀 다르다. 나중에 오프셋(두께 주기)이 올 때 그 방향을 정하려고 필요해진다 —
**그때 오프셋과 같이 온다.**

**자동 분류는 틀린다.** 사용자가 고칠 수 있어야 한다.

## 45-3 칠하기의 기제 — 면 위에서의 lift

**새 개념이 아니다. 선이 서는 것과 같은 문법이다.**

```
선   화면에 긋는다  →  축과 점이 3D를 정한다
칠   화면에 긋는다  →  그 아래 면이 3D를 정한다
```

면은 이미 3D 평면이니 화면 획을 그 평면에 역투영하면 끝이다.

**획이 화면에서 여러 면을 지나가면 면마다 나뉘어 얹힌다.** 손은 한 번 긋고 결과는 두 면에
붙는다. 사용자는 그걸 의식할 필요가 없고, 이것으로 「연속된 벽을 이어 칠할 수 없다」는
문제가 사라진다.

**어디서 칠하나.**
- **톤·명암은 지금 보는 시점 그대로.** 화면평면에 긋고 면에 얹히니 줄어듦이 저절로 맞는다.
  손이 정확할 필요가 없다. 전개도로 펴거나 날아갈 이유가 없다
- **정확한 형태는 면 정면 뷰에서** (44가 만든다). 줄어든 면에 정확히 그릴 수 있는 사람은 없다.
  그리고 면을 정면으로 보면 인접 면들이 **모서리로 서서 폭이 0이 되므로** 그 면만 칠해진다 —
  「주변 면도 칠할지」를 판정할 필요가 기하학적으로 없다

## 45-4 채움 — 두 종류를 데이터에서 갈라라

```
프리셋 채움   면의 성질이다. 「이 면 = 이 무늬」
손으로 칠함   그냥 획이다. 시스템은 그게 무엇인지 모른다
```

**이 구분이 안정성의 답이다.**

- **프리셋 채움은 면의 함수로 둔다.** 픽셀로 구워 두지 말고 면 경계에서 매번 만든다.
  그러면 창을 뚫어 경계가 바뀔 때 **자동으로 따라 잘린다.** 깨질 것이 없다 (원칙 b)
- **손으로 칠한 것은 획이라 안 따라간다.** 그게 맞다 — 손으로 칠한 건 손으로 지운다

**채운 면 위에 선을 그으면** 아무 일도 없어야 한다. 제도에서는 톤을 먼저 올리고 선을 위에 얹는다.
그 순서가 지켜지는지 확인하라.

## ⚑ 멈춰서 물을 것 — 해칭이 화면 고정인가 면 고정인가

- **화면 고정**이면 선폭(원칙 e)과 일관되고, 도면의 해칭은 원래 종이 위의 것이라 제도답다.
  대신 시점을 돌리면 무늬가 면 위에서 미끄러진다
- **면 고정**이면 면에 붙어 돌지만 3D 렌더처럼 보일 수 있다

**미리 정하지 마라. 둘 다 만들고 멈춰서 물어라.** 눈으로만 갈린다.

## 이 라운드에서 하지 말 것

- 광원을 놓으면 명암이 자동으로 나는 것 — 법선이 있으니 공짜지만 **그건 렌더링이고,
  그 순간 상용 3D툴이 된다**. 사람이 칠하는 일이다
- 재료 · 색 · 마커 — 46의 몫이다. 여기서는 기존 연필 표현으로 기제만 세운다
- 두께 추론 · 외벽/내벽 판정
- 전개도

## 재야 할 것

- 면 찾기: 놓침·과잉·구멍, 그리고 고친 뒤의 같은 수치
- 깊이 정렬: 겹친 면에서 앞뒤가 맞는가
- 분류: 법선 판정의 정확도, 경계 각도에서의 거동
- 칠하기: 화면 획이 면에 얹힌 좌표가 옳은가(원칙 d의 칠 판), 여러 면을 지날 때 나뉘는가
- 채움: 개구부를 뚫었을 때 채움이 따라 잘리는가, 안 깨지는가
- 면 정면 뷰에서 인접 면이 실제로 모서리로 서는가 (폭 0)
- 채운 면 위의 선이 정상인가
