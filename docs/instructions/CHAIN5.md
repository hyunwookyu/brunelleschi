# 사슬 규칙 — web2-62 → 63

한 세션(Fable 5.1)에서 이어 간다. **각 라운드를 완주·배포**하고 `web2/HANDOFF.md` §2를
갱신한 뒤 다음으로 넘어간다. **갈래를 먼저 딴다.**

## 이 사슬의 뜻 — **끝나면 바로 쓸 수 있어야 한다**

사람이 정했다(2026-09-04): 「**다 들어오면 좋지. 이것도 체인으로 쭉 가게 해서 끝나면
바로 써 볼 수 있는 건가.**」

```
62  엔진(libmypaint · ISC) + 브러시 196(CC0) + 올바른 합성 + 안료 혼합
63  비트맵 팁 + 종이 결 — 마른 매체의 «성격»이 여기서 완성된다
```

**63까지 끝나면 매체 전 범위가 손에 있다.** 그래서 이 사슬은 중간에 사람을 안 세운다.

⛳ **사람을 멈춰 세우지 마라.** 눈으로 판정할 것은 전부 **사진으로 남기고 실기기 항목으로
올린 뒤 계속 간다.** 51이 답을 기다리다 두 라운드를 잃었고, 그 뒤로 세운 규칙이다.

## 멈춤 조건 — 셋 중 하나면 멈추고 보고한 뒤 대기하라

```
① 측정이 지시문의 전제와 어긋난다
② 게이트가 통과 못 한다
③ 지시문에 없는 갈림이 나온다
```

지시문의 전제가 틀렸다고 판단되면 **고쳐서 진행하지 말고 멈춰라.**
**⚑ 표시는 멈춤 조건이 «아니다».**

## 이 사슬만의 조항 둘

**㉠ 62 안에서 «중간 보고»를 한 번 낸다.**
엔진과 합성이 서고 게이트 ①~⑤가 프리셋 한 줌으로 통과한 시점이다. 수치와 사진을 낸다.
**그것이 안 서면 196개를 실어도 소용없다** — 거기서 멈추고 보고하라.

**㉡ 흰 테 게이트는 무를 수 없다.**
「옅은 가장자리에서 RGB가 배경보다 밝아지지 않는다」가 이 사슬의 존재 이유다.
사람이 열네 라운드째 지적한 결함이다. **임계를 무르거나 표본을 좁히지 마라.**
`rgb ≤ a` 단언은 디버그 빌드에서 «항상» 돈다.

## 사람이 이미 정한 것 — 다시 열지 마라

```
· 칠 엔진을 직접 쓰지 않는다. 가져온다
· 매체를 좁히지 않는다 — 「건축에서는 안 쓴다」는 판단을 세션이 하지 마라
· 196개를 다 싣는다. 추리지 않는다
· 칠은 «면 위에서 도는 그림 그리는 툴»이다 — 부가기능이 아니다
```

## 모든 라운드에 적용

- CLAUDE.md §D · 게이트를 실제로 실행해 수치와 함께 보고
- 임계를 무르거나 픽스처를 쉽게 만들지 마라 · 새 임계는 `web/test/constants.ts`
- `Math.random` 금지 · `LEDGER=1` 없이 원장 쓰기 금지 · 원장 실행은 워커 1 (#99)
- 착수 시 **떠 있는 개발 서버를 내리고 새로 띄운다** (#70)
- 마감은 `deploy-check.mjs` · 대기에는 상한 (#81) · 마감 보고에 「도는 백그라운드 없음」을 값으로
- **라운드를 백그라운드 에이전트에 통째로 위임하지 마라** (#98)
- **손잡이를 추가하면 34-0 대조표(R1~R8)를 그 라운드 안에서 다시 돌려라**
- 새 저장 필드는 `KEY_ORDER`에 (43의 게이트 ②) — **다만 이 사슬은 저장 형식을 안 바꾼다**
- ⛳ **모든 라운드가 «사진»을 산출물로 낸다** — `web2/shots/`.
  게이트가 통과해도 사진이 나쁘면 그 라운드는 안 끝난 것이다
- **가져온 것 전부의 출처·라이선스를 마감 보고에 값으로 적어라**
