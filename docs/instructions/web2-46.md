# web2-46 — 재료: 색이 아니라 재료로 고른다

> **Fable.** 사슬 규칙은 `CHAIN.md`. 45의 칠하기 기제 위에 선다.

## 왜 「색」이 아니라 「재료」인가

건축가가 마커로 칠할 때 한 재료에 **밝음·중간·그림자**를 두고 면의 방향에 따라 골라 쓴다.
색을 고르는 게 아니라 재료를 고르고 그 안에서 톤을 고른다. 그게 머릿속 순서다.

```
재료 하나 = 톤 두셋(밝음·중간·그림자) + 해칭 무늬
벽돌 · 콘크리트 · 유리 · 나무 · 금속 …
```

45의 분류(슬라브·벽)가 여기서 값을 갖는다 — **기본 톤을 제안하는 근거**가 된다.
건축가가 투시도를 손으로 칠할 때 바닥·벽·천장을 다르게 하는 그것이 따라온다.
**제안이면 되고 기본값으로 박히면 안 된다.** 칠하는 건 사람이 하는 일이다.

## 색 — 이 앱에 처음 들어오는 개념

지금 연필 등급은 **농도**지 색이 아니다. 색이 들어오면 정할 것이 생긴다.
어떻게 고르게 할지는 맡기되, 지킬 것 둘.

- **팔레트를 「색 목록」으로 만들지 마라.** 재료 목록이어야 한다
- **스포이드는 나중이다.** 지금 화면에 뽑을 색이 없다. 배경 사진을 깔 수 있게 되면 그때 값이 생긴다

## 도구 — 연필만이 아니다

지켜야 할 것은 「연필」이 아니라 **실물 도구**다. 마커·색연필·수채는 전부 제도판 위의
물건이고 대응표 §0의 「실물 있음」 무리에 그냥 들어간다. 그리고 **건축 표현의 주력은
사실 마커다** — 프레젠테이션 드로잉에서 연필보다 훨씬 많이 쓰인다.

```
마커    이번에 넣는다. 성질 둘만 재현하면 그 느낌이 난다 —
        겹치면 진해진다 · 획 경계가 살짝 남는다
색연필  이번에 넣는다
수채    넣지 마라. 번짐이 유체 문제라 무겁다
```

**`p5.brush`에 무엇이 있는지 먼저 보고 모자란 것만 채워라.** 이미 쓰고 있는 것이니
새 의존을 지기 전에 거기서 얼마나 나오는지 확인하고 보고하라.

**아이콘은 `docs/instrument-icons.md`의 선 문법을 따른다.** 기존 아이콘을 다시 그리지 마라.

## ⚑ 멈춰서 물을 것

마커·색연필이 **건축 표현으로 쓸 만한가**는 눈으로만 갈린다.
값을 붙들고 오래 만지지 말고, 한 판을 세운 뒤 실기기 확인 항목으로 올려라.

## 재야 할 것

- 마커의 두 성질: 겹침의 농도 증가가 실제로 누적되는가, 획 경계가 남는가 (수치로)
- 45의 채움·칠하기 무회귀 — 기제는 안 바뀌고 표현만 는다
- 분류가 제안한 기본 톤이 **제안에 그치는가** (사람이 바꾸면 그대로 남는가)
- 성능: 재료가 는 뒤 획 200개 장면의 프레임
- 저장 왕복 — 재료·색이 43의 왕복 팔에 들어갔는가. **43이 만든 전수 목록을 갱신하라**
