# web2-55 — 두께와 분류

> **Fable.** 방법은 맡긴다 — 무엇을 지키고 무엇을 잴지만 적는다.
> 사슬 3의 둘째 라운드다(`CHAIN3.md`). **54가 배포된 뒤에 착수한다.**

## 왜

**지금 벽은 선 하나다.** 건축가에게 그건 스케치지 도면이 아니다.
그으면 서고 치수가 실측인 것까지는 됐는데, **벽이 벽이 아니다.**

목표가 유료 상용앱으로 바뀐 뒤 남은 큰 구멍은 이것 하나다.

## 결정 — 사람과 확정한 것 (2026-09-01/02)

```
분류가 든다        t(두께) · 오프셋 기준 · 기본 재료 · 우선순위
면은 가리킨다      분류를 가리키고 «예외만» 덮어쓴다        ← BIM의 type/instance
면은 세 슬롯       앞 · 뒤 · 테두리
t = 0 이 기본      테두리 폭이 0일 뿐 슬롯은 처음부터 있다
```

**왜 두께를 면에 직접 안 두는가**: 사람의 말 그대로다 — 「폭은 앞으로 생길 레이어
(외벽·내벽·기타등등)에 따라 **일괄적으로** 줄 것」. 면마다 들면 일괄이 안 된다.

**왜 t=0을 처음부터 두는가**: 두께를 「나중에 더하는 것」으로 두면 그 날 칠 데이터를
옮겨야 한다. **「항상 있는데 0이다」로 두면 옮길 일이 영원히 없다.**
50이 「마이그레이션을 만들지 마라」로 간 것과 같은 자리다.

**테두리는 단면이 아니다.** 사람이 잡은 구분이다 — 「벽이 중간에 끝날 수도 있고 문틀일
수도 있는데 단면으로만 처리할 수는 없다」. **테두리는 실제 표면이고 칠할 수 있다.**
단면은 **뷰가 자를 때 생기는 것**이고 이 라운드에 없다.

## ⚠ 착수 전에 — **45·46이 이미 넣은 것을 코드로 확인하고 보고하라**

- **45**가 「법선 분류(슬라브·벽·경사)」와 **손통 「분류」**를 넣었다(자동 분류 + 사람 정정)
- **46**이 그 분류에 재료를 붙였고 분류가 톤을 제안한다
- **50**이 칠의 정본을 「면 위 좌표」로 놓았다

**새로 만드는 것이 아니라 그 분류에 t·기준·우선순위를 얹는 것이다.**
45의 법선 분류를 갈아엎지 마라 — **어휘를 넓히는 일**이다(벽 → 외벽·내벽).

## 분류가 드는 것

```
t              두께 (mm)
오프셋 기준     가운데 / 한쪽          ← 중심선이 벽의 어디인가
우선순위        정수 · 큰 쪽이 이긴다   ← 56이 쓴다. 이번엔 «들고만» 있는다
코어 여부       참/거짓                ← 56이 쓴다. 2단 정렬 키의 윗자리
기본 재료       46의 것 그대로
```

**초판값은 사람이 바꾸는 것을 전제로 한 곳에만 둬라**(원칙 a).
값 자체는 세션이 정하되 **근거를 원장에 남겨라**. 오프셋 기준의 기본은 **가운데**다 —
손으로 그은 선이 벽의 어디인지 앱이 알 수 없기 때문이고, 예측 가능한 쪽이다.

**우선순위를 재료가 아니라 분류에 두는 이유**: ArchiCAD는 재료에 둔다(그쪽이 더 낫다).
다만 우리는 아직 복합벽이 없고 분류당 층이 하나다 — **재료로 옮기는 것은 복합벽이 생기는
날의 일이고, 그 날 옮길 수 있게 «분류가 재료를 가리키는» 꼴을 지켜라.**

## 세 슬롯의 좌표 — 두께가 바뀌어도 칠이 안 늘어난다

```
앞 · 뒤     면 위 좌표 (미터)          — 50이 정한 것 그대로
테두리      (경계 거리 s, 두께 방향 u) — 둘 다 «미터»
```

⚠ **정규화 좌표(UV)를 쓰지 마라.** t를 200 → 300으로 바꾸면 테두리 칠이 1.5배로
늘어난다. s·u가 미터면 안 늘어나고 **새로 생긴 폭이 빈 채로 남는다** — 그것이 옳다.

## 이번 회차의 범위 — **벽 «한 장»이 두께를 갖는 것까지**

- **접합은 56이다.** 자유단 캡은 평평하게(butt). **코너에 계단이 나도 된다** —
  그것이 56이 고칠 것이다
- ⚠ **여기서 접합에 손대면 두 라운드가 섞여 무엇이 고쳤는지 모르게 된다**

## 게이트

- **t = 0 이면 지금과 픽셀이 같다** ← **이 라운드의 중심 게이트다.**
  두께가 「항상 있는데 0」임을 값으로 증명한다
- **분류를 바꾸면 그 분류를 가리키는 면 «전부»의 두께가 바뀐다**(일괄) ·
  **예외를 준 면만 안 바뀐다**
- **앞/뒤 칠이 두께를 준 뒤에도 같은 자리에 있다** — t를 0 → 200 → 0으로 왕복하면
  픽셀이 복귀한다
- **테두리 칠이 t를 바꿔도 안 늘어난다** — t를 200 → 300으로 바꾸고 칠의 자국 크기를
  재라. 커지면 UV를 쓴 것이다(D-3 반증)
- **반증**: 예외를 준 면에 분류의 t를 다시 밀어 넣으면 예외가 덮인다(계측이 살아 있음)
- **저장 왕복** — 새 필드를 **KEY_ORDER에 적어라**. 43의 게이트 ②가 안 적으면 빨개진다
- 성능: 면 20개 · 두께 있는 장면의 프레임·메모리
- 기존 전부 무회귀
