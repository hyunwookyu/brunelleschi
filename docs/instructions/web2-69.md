# §1 전수 — 표 하나

앱을 기본 상태로 띄우고(새 문서 · 아무 도구도 안 든 상태 · 저장된 설정 없음) **화면에 보이는 누를 것**을 전부 센다. 그 다음 도구를 하나씩 들고(연필 · 펜 · 지우개 둘 · 면 · 칠) 그때 «더» 나타나는 것을 센다. `index.html`의 id 122개와 `main.ts`가 만드는 것(칠 패널 · 필통 · 통들)을 합친다.

표는 `docs/reference/INVENTORY.md`. 열:
```
id · 자리(위/왼/오른/아래/떠 있음) · 종류(단추/토글/슬라이더/입력/글자) · 글자 라벨 있음? · 툴팁 있음? ·
언제 쓰는가(획마다 / 문서마다 한 번 / 가끔 확인 / 개발) · 지금 탭 수 · 판정(§2) · 뒤 탭 수
```
참고 잣대: `docs/reference/UX-FLOWS.md` §A-0(Feather 19) · §C-0(Procreate 15) · §D-0(Trace 50+) · §E 표.

**게이트**: 표의 행 수 == DOM에서 실측한 누를 것의 수(스크립트로 센다 — 손으로 세지 마라) · 기본 상태 셈 값 · 도구별 추가 셈 값.

# §2 판정 규칙 — 넷. 규칙에 안 걸리는 것이 나오면 «상시»로 두고 ⚑

```
R-A  획을 긋는 동안 한 번 이상 쓰는가             → 상시 (도구 · 되돌리기/다시하기 · 필통 · 지금 색/브러시 · 크기 · 불투명 · 축 스냅 · 시점 맞춤)
R-B  문서에서 한 번 정하는 것인가                  → 카드(설정) (축척·단위 · 종이 종류 · 표시 토글들(지평선·격자·안개·숨은선·해칭) · 홀드 시간)
R-C  가끔 확인하는 것인가                          → 카드(보기) 또는 부르면 얹힘 (바닥면적 · 실 다이어그램 · 치수판 · 렌즈 · 사람 놓기 · 저장/열기/내보내기)
R-D  개발용인가                                    → 개발 메뉴(URL `?dev=1` 또는 설정 카드 맨 아래 접힘) (diag · tunelab · press-calib · buildid · oldtools · chk-own3d)
```
- **제도판의 것은 상시다**(DIRECTION 「시작은 종이다」): 축척 표식(정사 「1:N」+화면 폭 실치수 / 투시 눈높이·거리) · 굵기 눈금 · 제도 연필 경도. 없던 표식은 **이 라운드에서 만들지 않는다** — 자리만 비워 둔다(72의 일). 있는 것은 상시로 둔다.
- 카드는 **기존 통**이다(`boxes.ts` registerBox · R7 한 번에 하나). 새 통을 짓지 말고 있는 통에 넣는다. 설정 카드가 없으면 `display-pop`을 설정 카드로 승격한다(이름 「설정」).
- 상시 목표: **기본 상태 ≤ 20 · 칠 도구 든 상태 ≤ 32**(Feather 19 + 필통 8 + 제도판 것). 넘으면 표에 «왜»를 적고 넘긴다 — 억지로 접지 마라(⚑).
- 글자 라벨·툴팁·아이콘은 **건드리지 않는다** — 70의 일이다. 이 라운드는 «자리»만.
- 격자 표시 기본값: **새 문서는 꺼짐**(DIRECTION). 저장된 설정이 있으면 그것을 따른다. 축 스냅은 무관(그대로 켜짐).

**게이트**: 표의 판정 열이 전부 채워졌다 · ⚑ 행 수(값) · 목표 수 달성 여부(값 — 못 넘어도 멈추지 않는다).

# §3 실행 — 표대로 옮긴다

- R-B·R-C·R-D 판정을 받은 것을 그 카드로 옮긴다. **id는 바꾸지 않는다**(e2e가 id를 잡는다 — 자리 이동은 스펙의 «열기» 한 줄만 바뀐다).
- 옮긴 것은 **2탭 안에** 닿아야 한다(카드 열기 1 + 누르기 1). 표의 「뒤 탭 수」가 그 값이다.
- 개발 메뉴는 `?dev=1`이 없으면 DOM에 없다(hidden이 아니라 미생성 — 셈에서 빠진다). e2e는 `?dev=1`로 연다.
- 34-0 대조표(R1~R8)를 이 라운드 안에서 다시 돌린다 — 접은 것이 R3(「또 쓸 것 같은가」)에 걸리면 되돌린다.

**게이트**
- **전수 왕복**: 표의 모든 id가 여전히 닿는다(e2e — id마다 열어서 누른다 · 하나도 빠지지 않는다 = 「기존 기능 전부 살아 있음」의 검사).
- 기본 상태 셈 전/후(값) · 칠 도구 셈 전/후(값) · 모든 행 뒤 탭 수 ≤ 2.
- 새 문서 격자 꺼짐 · 저장 설정 존중 · 축 스냅 무변.
- 65·66·67 게이트 무회귀 · e2e 전량(자리 이동으로 갈린 스펙만 고친다 — **지운 시험 0**).
