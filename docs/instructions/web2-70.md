# §1 토큰 — 파일 하나

지금 색은 `main.ts`·`brushpicker.ts`·`index.html` 안 문자열에 흩어져 있다(실측: `#fffdf8` 6 · `#f5f3ee` 5 · `#3c3831` 5 · `#000000` 5 · `#d8d2c4` 4 · `#8d8880` 4 · `#8a7f6a` 3 · `#e9d98a` 2 · `#c9c2b4` 2 …). 전부 **`web2/src/ui/tokens.css`** 한 파일의 변수로 모은다.

```
--paper        종이(캔버스 바탕)            #f5f3ee  (앱 아이콘의 그 색 — 바꾸지 않는다)
--panel        판(알약·카드)                종이보다 한 단 밝고 불투명: #fbfaf7  · 어두운 판 변형 [data-theme=dark] #1f1f1f~#2a2a2a
--ink          아이콘·글자                  #3c3831  (dark: #e8e6e1)
--ink-2        보조 글자·숫자 라벨          #8d8880
--line         구분선(쓰면 1px · 최소)      #d8d2c4
--accent       강조색 **하나**               §2에서 정한다
--select       선택된 획                    초록(기존 값 유지 — Feather 관습과 같다)
--radius       판 둥글기                    12px   (Feather 12 · Procreate 14 · Trace 4 사이 — UX-FLOWS §G-4)
--gap          간격 단위                    8px    (모든 여백은 8의 배수 · 아이콘 안 여백 4)
--icon         아이콘 격자                  24px · 선 1.75px
--tap          누를 것의 최소 크기          44px   (손가락 — 67이 손가락 탭을 살렸다)
--num          숫자 라벨                    10px · tabular-nums
그림자 없음 · 테두리 없음(판은 색 차로만 뜬다) · 반투명 없음(3D 선이 뒤에 있다 — §G-5)
```
- **기본은 밝은 종이 판**이다 — 앱의 얼굴(아이콘 · 종이색)이 이미 그렇고, Feather 1.x·Trace 종이도 밝다. 어두운 판은 `[data-theme=dark]`로 **같은 토큰 이름**에 값만 바꿔 준비하고 **사진으로 둘을 나란히** 남긴다(사람이 뒤에 고른다 — 멈추지 않는다).
- 판 위의 판(카드 안 단추)은 `--panel`보다 한 단 어둡게(색 차 ≈ 4%).

**게이트**: `src/**` 문자열과 `index.html`의 16진수 색 수 → **0**(tokens.css 밖 · SVG 도구 그림의 fill은 `currentColor`/변수) · 토큰 수(값) · dark 변형이 토큰 전부를 덮는다(빠진 변수 0).

# §2 강조색 하나 · 상태 셋

후보 둘: 기존 노랑 계열(`#e9d98a`의 진한 판) · 잉크 파랑(`#2b5bd7` 근방). **대비로 판정**한다 — `--panel` 위에서 글자 4.5:1 · 아이콘 3:1(WCAG 값). 둘 다 넘으면 노랑(제도판 — Trace 관습). 하나만 넘으면 그것. 값과 대비 비를 원장에.

상태는 셋뿐이다(UX-FLOWS §E 합의 ④·⑥):
```
선택됨     아이콘 색 = --accent (Procreate) — 반전 원(Trace)은 쓰지 않는다
못 누름    불투명 .35 — 자리는 그대로(되돌리기·다시하기가 이 규칙의 첫 손님)
눌림       배경 --panel 을 8% 어둡게 (호버는 데스크톱만 · 터치에 호버 상태 없음)
```
**게이트**: 대비 비 값 · 선택/못 누름/눌림 상태가 CSS 클래스 셋으로만 표현된다(인라인 style 0) · 되돌리기 못 누름 = .35 실측.

# §3 아이콘 한 세트

지금: 글자 단추 · 이모지 · 손그림 SVG가 섞여 있다. **한 세트**로.
```
바탕 세트   MIT 또는 ISC 아이콘 세트 하나(Lucide ISC · Phosphor MIT · Tabler MIT 중 하나 — 선 굵기를 1.75로 맞출 수 있는 것) — 라이선스 파일을 저장소에
우리 그림   바탕 세트에 없는 것(도구 일곱 · 지우개 · 면 · 정면 · 축 스냅 · 시점 · 필통 칸의 도구 그림(68))은 같은 24px 격자 · 같은 1.75px 선으로 직접 그린다
크기        24px 하나(필통 칸 안 도구 그림은 32px — 둘만)
색          currentColor — 토큰이 정한다
```
- 아이콘이 있는 단추의 **글자 라벨은 뗀다**(세 앱 합의 ⑧). 예외: 분할 단추(Draw|Loft 꼴)와 숫자 라벨(크기 mm · 불투명 % · 경도 · 축척). 뗀 라벨은 `aria-label`로 남긴다(접근성 · 툴팁 논의와 별개).
- 제도 연필·펜의 «심 그림»(fold-lead · fold-nib)은 우리 것이다 — 같은 선 굵기로 다시 그리되 **경도 글자는 남긴다**(제도판의 것).
- 68의 필통 도구 그림이 이 세트의 첫 손님이다 — 68이 그린 SVG를 이 격자에 맞춘다(다시 그리지 말고 맞춘다).

**게이트**: 이모지 0 · 글자만인 도구 단추 0(분할·숫자 예외 목록은 값으로) · 아이콘 선 굵기 실측 하나(SVG stroke-width 전수 grep) · 라이선스 파일 · **⛳ 사진** `70-icons.png` — 쓰는 아이콘 전부를 한 판에.

# §4 판과 글자

- 모든 판(칠 패널 · 통 · 카드 · 필통 · 브러시 목록 · 상태줄)이 `--radius` `--gap` `--panel`을 쓴다. 판마다 다른 둥글기·여백 0.
- 글자: 시스템 글꼴 스택(`system-ui, -apple-system, "Segoe UI", sans-serif` + 한글 폴백) · 크기 셋만(10 숫자 · 12 본문 · 14 제목). 볼드는 제목만.
- 숫자 라벨은 `font-variant-numeric: tabular-nums` — 값이 바뀌어도 폭이 안 뛴다.
- 상태줄(status)은 남는다 — 한 줄 12px · 판 아래. 토스트는 67-0-1의 결정대로 표식으로.

**게이트**: 둥글기 값 종류 1 · 여백 값이 전부 8의 배수(CSS grep) · 글자 크기 종류 3 · `70-panels.png`(모든 판을 연 합성 한 장 · 밝은 판) · `70-panels-dark.png`(같은 것 어두운 판) · 69의 셈 무변(자리 안 바꿈) · 전수 왕복(69 게이트) 무회귀 · e2e 전량 — **지운 시험 0**(글자 라벨을 잡던 스펙은 id/aria-label로 바꾼다).
