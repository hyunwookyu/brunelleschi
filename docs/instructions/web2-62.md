# web2-62 — mypaint 엔진 이식

> **Fable 5.1.** 61이 배포된 뒤에 온다. **새 세션이다**(이식이라 컨텍스트가 깊다).
> 61이 만든 **이음매 뒤**만 갈아끼운다 — 그 밖을 건드리면 범위를 넘은 것이다.

## 왜

61은 p5.brush를 넣었다. 좋은 라이브러리지만 **브러시 9개짜리 제너러티브 아트
라이브러리**다. mypaint는 **15년짜리 회화 엔진**이고, 화가들이 만든 브러시가
**200여 개** 딸려 온다. 천장이 다르다.

사람의 물음이 이 라운드의 근거다.

> 「퀄리티 좋은 수많은 칠·브러시·마커 도구가 있는데 **우리가 이 값을 시간 들여 찾아야 하나?**」

**아니다. 그래서 200개를 가져온다.** 사람이 하는 일은 값을 «찾는 것»이 아니라
**고르는 것**이 된다.

## 라이선스 — 원문에서 확인했다

```
libmypaint        ISC        안전하다 (유료 폐쇄 소스에 써도 된다)
mypaint-brushes   CC0 1.0    **의무가 아예 없다.** 프리셋을 그대로 실어도 된다
⛔ MyPaint 앱 자체  GPL        ⛔ 저장소를 열지도 마라. 우리가 쓰는 것은 위 둘뿐이다
```

⚠ 마감 보고에 **패키지·커밋·라이선스 파일 경로를 값으로** 적어라.

## 이식 범위 — **전부 옮기지 마라**

libmypaint는 타일 서피스·색 관리·GEGL 연동까지 들어 있다. **우리는 대부분이 필요 없다.**

```
옮긴다
  ① dab 루프          count_dabs_to — «거리 기반» 도장 배치. 남은 거리를 이벤트 사이로 이월
  ② 설정 × 입력 응답곡선 ~40 설정 × ~10 입력(압력·속도1·속도2·방향·기울기·난수·획 진행)
                       각 칸이 곡선 하나다. **이 표가 곧 엔진이다** — 도장 자체는 사소하다
  ③ 타원 도장          hardness · elliptical_dab_ratio · anti_aliasing
  ④ 흔들림             offset_by_random · radius_by_random
                       ⚠ 반지름 흔들림은 알파를 보정한다: alpha_correction = (실제r/r)²
  ⑤ opaque_linearize   겹치는 도장의 비선형을 푼다 — 도장별 알파를 이렇게 낸다:
                         dabs_per_pixel = (dabs_per_actual_radius + dabs_per_basic_radius)×2
                         beta_dab = (1−opaque)^(1/dabs_per_pixel)
                         도장 알파 = 1 − beta_dab
                       59가 스트로크 버퍼로 푼 문제의 «싼 근사»다 — 둘이 겹치니 주의
  ⑥ .myb 프리셋 파서   mypaint-brushes의 형식

안 옮긴다
  타일 서피스          우리는 2D 캔버스에 그린다
  색 관리 · GEGL       필요 없다
  MyPaint 앱의 무엇도  ⛔ GPL
```

## 반드시 지킬 것

```
61의 이음매          ⛔ 그 «뒤»만 바꾼다. 부르는 쪽이 mypaint를 알면 안 된다
50   정본은 획 목록, 파생은 텍스처 · 텍스처는 저장 안 한다          ⛔ 불변
55   앞·뒤·테두리 · 칠 좌표는 면 위 미터 좌표                       ⛔ 불변
56   접합 무회귀                                                    ⛔ 불변
59   미리보기 == 확정본 · 획 «안»에서 안 쌓인다 · 결은 면 고정        ⛔ 불변
46   마커는 겹치면 진해진다                                         ⛔ 불변
58   크기 슬라이더와 도구별 최대                                    ⛔ 불변
저장 형식 · KEY_ORDER                                              ⛔ 불변
```

⚠ **59의 스트로크 버퍼와 ⑤ opaque_linearize가 «같은 문제»를 푼다.**
둘 다 걸면 이중으로 옅어진다. **어느 쪽이 정본인지 정하고 원장에 값으로 남겨라**
(권고: 스트로크 버퍼가 정본 · opaque_linearize는 1.0이 아니라 0으로 두고 시작 —
다만 재서 정하라. 프리셋의 값이 그 전제로 만들어졌으므로 그대로 두는 편이 나을 수도 있다).

## ⚑ 사람이 고른다 — **이 라운드의 마지막 절**

프리셋 200여 개를 다 실을 필요가 없다. **사람이 사진을 보고 고른다.**

1. 후보를 **분류별로** 추려라 — 연필 / 색연필 / 목탄 / 마커·잉크 / 붓
   (건축 스케치에 쓸 만한 것으로. 수채·유화·특수효과는 빼라)
2. 후보마다 **획 셋(직선·물결·자기교차)을 그린 PNG**를 낸다.
   한 장에 격자로 모아 이름을 붙여라
3. **거기서 멈추고 사람에게 물어라.** 고른 것만 도구 넷에 배정한다

⚠ **세션이 고르지 마라.** 그것이 이 라운드의 뜻이다.

## 게이트

61과 **같은 자를 쓴다** — 나란히 비교할 수 있어야 한다.

```
① 격자 주기 진폭 ≈ 0        ② 도장 주기 진폭 ≈ 0
③ 구멍이 격자에 안 실린다    ④ 굵기를 2배로 해도 결 주기가 안 따라 커진다
⑤ 넷이 통계로 갈린다
⑥ 결정론 — 같은 획·같은 시드면 같은 픽셀 (Math.random ⛔)
```

**⛳ 사진을 남겨라** — `web2/shots/62-<brush>.png`.
**그리고 61의 사진과 나란히 붙인 비교 한 장**(`web2/shots/62-vs-61.png`)을 내라.
그것이 「mypaint가 나은가」의 답이고, 사람이 그걸로 판정한다.

무회귀: 50·55·56·59·61의 게이트 전부 · `roundtrip43` ② · 성능(면 20 · 획 40).
