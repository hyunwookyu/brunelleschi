# 사슬 규칙 — web2-68 → 69 → 70 → 71

한 세션(Fable 5.1)에서 이어 간다. **각 라운드를 완주·배포**하고 `web2/HANDOFF.md` §2를 갱신한 뒤 다음으로 넘어간다. **갈래를 먼저 딴다.**
세션이 끊기면 다음 세션은 **HANDOFF §1이 가리키는 라운드부터** 이어 간다 — 이 문서를 다시 읽고.

## 이 사슬의 뜻 — 필통과 UX를 한 번에

사람이 정했다(2026-09-05): 「67까지 끝났고, 그 이후 **필통과 UX 모두 한 번에 완주하도록**.」

```
68  필통       — 즐겨찾기 여섯 → 필통 여덟 · 연필 HB~8B 여섯 · 목탄 셋 · 도구 그림에 색 · 브러시 목록 두 칸 · 눈금 표식
69  인벤토리   — 화면의 누를 것 전수 · 규칙 넷으로 자리 판정(상시/설정 카드/보기 카드/개발) · 옮긴다 · 지우지 않는다
70  시각 시스템 — 토큰 파일 하나 · 강조색 하나 · 아이콘 한 세트(MIT/ISC + 우리 그림) · 글자 라벨 뗌 · 둥글기·간격 하나
71  몸짓       — 두/세 손가락 두드림 · 세 손가락 두 번 격자 · 한 손가락 두 번 정사 · 재누름 = 카드 · 칠 획 끝 멈춤 = 직선 띠
```

**71까지 끝나면 「AI가 만든 티」가 벗겨진 첫 판을 사람이 손에 든다.** 그래서 중간에 사람을 안 세운다.

⛳ **사람을 멈춰 세우지 마라.** 눈으로 판정할 것은 전부 **사진으로 남기고 실기기 항목으로 올린 뒤 계속 간다.**
69의 판정은 규칙이 한다 — 규칙에 안 걸리면 상시로 두고 ⚑. 70의 밝은/어두운 판은 둘 다 사진으로 — 기본은 밝은 종이 판.

## 멈춤 조건 — 셋 중 하나면 멈추고 보고한 뒤 대기하라

```
① 측정이 지시문의 전제와 어긋난다
② 게이트가 통과 못 한다
③ 지시문에 없는 갈림이 나온다
```
지시문의 전제가 틀렸다고 판단되면 **고쳐서 진행하지 말고 멈춰라.** **⚑ 표시는 멈춤 조건이 «아니다».**

## 이 사슬만의 조항 셋

**㉠ 기존 기능은 전부 살아 있다.** 69의 「전수 왕복」(표의 모든 id가 닿는다)이 그 검사고, 70·71도 그것을 무회귀로 돈다. 「삭제」 판정은 없다 — 옮기고 접고 숨긴다(개발 메뉴).

**㉡ DIRECTION 「재검토 대기」 둘은 건드리지 않는다.** 조명·그림자 / 툴팁. 판정 전이다. 70이 글자 라벨을 떼는 것은 툴팁과 별개다(aria-label로 남긴다).

**㉢ 문서 먼저.** 68 §0이 사람의 두 문서(DIRECTION 교체본 · UX-FLOWS)를 첫 커밋으로 넣는다. 그 뒤의 모든 판정은 그 문서를 근거로 인용한다(어느 절인지).
