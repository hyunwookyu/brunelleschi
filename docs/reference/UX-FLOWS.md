### A-0 기본 화면 — 있는 것 «전수» (0:58 · 1:15 · 1:42 프레임)

캔버스가 화면 전부다. 떠 있는 것은 **흰 반투명 알약(pill) 넷 + 손잡이 둘**뿐이다.

```
왼쪽 위    알약 하나  ⊞(격자) · ↑(내보내기/공유) · ≡(목록)          + 따로 떨어진 (?) 도움말
오른쪽 위  알약 하나  ▲(윤곽 삼각 · 지금 선택돼 밝음) · ⬒(상자 아래 반) · ▲(속 찬 삼각)
                     ┃ 구분선 ┃  ◧(거울) · ▭(액자) · ⊟(겹친 판)         → 3 + 3
왼쪽 세로  알약 하나  위에서부터:
                     [붓/폴더 모양] 브러시 고르기?
                     ● 검은 원      ← 지금 색 (색 견본이 «칸»이 아니라 «점»)
                     ─ 구분선
                     ○· 작은 원     크기?
                     ● 회색 원      불투명도?
                     ─ 구분선
                     💉 주사기      Injector(스포이드+ · 조사에서 확인한 그것)
           그 아래 작은 흰 알약 하나 (비어 있음 — 슬라이더가 나올 자리?)
왼쪽 가장자리  ◂ 작은 탭 (세로띠 접기 손잡이?)
아래 가운데  분할 단추  「✎ Draw │ Loft」 — Draw 선택, Loft 흐림
위 가운데   ••• (끌기 손잡이 · iPad 멀티태스킹)
```

**셈**: 상시 보이는 누를 것 = 4 + 1 + 6 + 6 + 2 ≈ **19**. 글자는 「Draw」「Loft」 둘뿐.
**자막 1:42**: 「화면 왼쪽에서 브러시 옵션을 조절하고, 히스토리 패널에서 작업을 되돌리거나 다시 실행할 수 있습니다.」
**자막 1:54**: 「홈으로 돌아가기 위해 오른쪽 상단의 아이콘을 탭하세요.」 (? 오른쪽 상단 = 파일 화면의 것 — 1:54 프레임은 손이 가려 못 봄)

**시각**: 아이콘은 전부 «검은 선 하나의 굵기», 흰 반투명 알약 위. 모서리 큰 둥글기. 라벨 없음.

### A-1 그리기와 지우기 (2:04–6:47) — 프레임 2:10 · 2:27 · 2:44 · 3:02 · 3:20 · 3:40 · 4:00 · 4:20 · 4:40 · 5:00 · 5:20 · 5:40 · 6:00 · 6:20 · 6:40

**되돌리기/다시하기**
- 3:02 자막 「화면 왼쪽에서 화살표 모양의 버튼을 여러 번 눌러 작업을 되돌려주세요.」

**격자·축**
- 3:20 자막 「화면에 빨간색, 녹색, 파란색 선이 보일 것입니다.」 3:40 「세 손가락으로 더블 탭한 뒤 진행하겠습니다.」 → **세 손가락 두 번 두드림 = 격자·축 켜기/끄기**. 3:20 빈 화면(축만 희미), 3:40 이소메트릭 격자 + 빨강·초록·파랑 축.
- 격자는 아주 옅은 회색 선. 축 세 개는 각각 옅은 빨강·초록·파랑. 바닥 격자가 화면 전체에 깔린다(끝이 없다).

**정사(ortho) 보기**
- 4:20 자막 「그리고 상단으로 이동하여 더블 탭합니다.」 5:00 「프론트 뷰로 이동하여 다시 더블 탭하고」 → **한 손가락으로 돌려서 위/앞 가까이 간 뒤 두 번 두드림 = 정사 뷰로 딱 맞춤.** 정사로 들어가면 격자가 **정사각형 격자**로 바뀌고, 화면 **아래 가운데에 「—×—」** 작은 표식이 뜬다(정사 잠금 표식?). 이때 Draw|Loft 분할 단추는 사라진다(4:20 · 5:00 · 6:00 프레임 모두 없음) → **정사에서는 로프트가 없다**.
- 4:20 프레임: 정사로 들어가는 순간 화면 가운데에 **세로로 긴 밝은 띠**(가이드 면을 옆에서 본 것?)가 보인다.

**세로띠의 점**
- 4:00 프레임: 손이 세로띠 「○·」 자리를 누르자 그 원이 **테두리만 남은 빈 원**이 된다(눌림 상태). 자막 「다른 곳을 터치하여 패널을 닫아줍니다.」 → **누르면 옆으로 패널이 펼쳐지고, 캔버스 아무 데나 두드리면 닫힌다.** (펼쳐진 패널 자체는 손에 가려 못 봄 — 파트 1의 다른 프레임에서 다시 찾는다.)

### A-3 칠 (7:24–10:27) — 프레임 7:22 · 7:26 · 7:30 · 7:34 · 7:38 · 7:41 · 7:44 · 7:47 · 7:49 · 7:58 · 8:00 · 8:02 · 8:06 · 8:08 · 8:10 · 8:12 · 8:26

**브러시 고르기 (7:26)** — 세로띠 맨 위 아이콘을 누르면 **세로띠 자체가 브러시 목록으로 바뀐다**: 같은 자리에 위아래로 **6개 아이콘**(펜촉·마커(검게 채워진 것 = 지금)·납작붓·빗금붓·둥근붓·붓끝 …), 라벨 없음, 색·크기·불투명 점은 그동안 **사라진다**. 하나 누르면 목록이 닫히고 원래 세로띠로 돌아오며 맨 위 아이콘이 고른 브러시 모양으로 바뀐다.
  - 자막 「브러시 종류 아이콘을 탭하고 형광펜 모양의 브러시를 선택하세요. 크기를 170mm로 변경합니다.」 7:22 「플랫 브러시로 바꿔줍니다.」 → 브러시 이름은 자막에만(형광펜 · 플랫). 화면엔 그림뿐.
  - **크기 단위 = mm(실치수).** 「170mm」.

**크기 입력 (7:30)** — 크기 점을 누르면 점 왼쪽 아래에 「1mm」 작은 라벨이 뜨고, 그 **오른쪽에 숫자판(1–9 · ⌫ · ↵)**이 붙는다. 슬라이더가 아니라 **숫자를 친다**. ↵는 옅은 초록, ⌫는 옅은 빨강. (세로띠는 숫자판 동안 빈 알약으로 남고 되돌리기만 보임.)

**색 고르기 (8:08)** — 색 점을 누르면 점 **오른쪽에 카드**(≈ 210×250): 위 왼쪽 **16진수 글자칸**(「385593」식), 위 오른쪽 **스포이드 아이콘**, 가운데 **색상 고리(무지개 링) 안에 SV 사각형**. 손잡이 = 링 위 작은 흰 원 하나, 사각형 안 흰 테 원 하나. **견본·프리셋·최근 색 없음.** 캔버스 두드리면 닫힘. 고른 색은 세로띠의 점 채움색으로 바뀐다(8:00 살구색, 8:10 파랑).

**그리기 방식(직선 모드) (7:38–7:47)**
  - 7:34 자막 「이 브러시로 그리면, 선의 끝이 자주 지저분해집니다.」 (납작붓으로 손으로 그으면 끝이 너덜너덜한 검은 덩어리 — 프레임 7:34.)
  - 7:38 「드로우 아이콘을 다시 탭해서 모드를 바꿔줍시다.」 → **오른쪽 위 첫 아이콘(▲)을 다시 누르면 ▲ 밑에 «자 눈금 줄»이 붙은 모양으로 바뀐다 = 직선(자) 모드.** 같은 단추가 «도구»이자 «모드 순환».
  - 7:44 「이 드로우 모드에서 직선을 그린 후 잠시 동안 기다리면 끝점을 조절할 수 있습니다.」 → 직선 모드에선 납작붓 한 획이 **각진 띠(직사각형)**로 떨어지고, 그은 뒤 **펜을 떼지 않고 잠시 멈추면** 끝점을 끌어 길이·각도를 맞춘다. 7:49 「이 기능을 사용하여 칠해주겠습니다.」 → **면 칠 = 굵은 납작붓 + 직선 모드 띠 여러 개.** 채우기(fill) 도구가 없다.
  - 8:12 프레임: 살구색 띠 하나로 상자 윗면 전체가 덮임(띠 굵기 170mm). 파란 띠는 그 아래. 획 끝이 사각형 테두리를 «넘친다»(8:00 프레임 왼쪽 위 삐져나온 살구색).

**정사에서 칠하기** — 칠은 전부 정사(앞·옆)에서 「—×—」 표식 뜬 채로 한다. 8:26 「이쪽은 약간 더 어두운 면이므로, 더 어두운 색을 사용합니다.」 → 옆 정사로 돌려 더 어두운 파랑 띠. **명암 = 사람이 면마다 색을 고른다.** 자동 음영 없음.

**셈 (칠 한 번의 탭 수)**: 브러시 바꾸기 2탭(열기·고르기) · 크기 = 1탭 + 숫자 + ↵ · 색 = 1탭 + 링 끌기 + 사각 끌기 + 캔버스 탭 · 모드 = 1탭. 

**색 카드는 그리는 동안 열려 있어도 된다** — 8:41 · 9:21 · 11:09 · 15:57 · 16:17 프레임 전부 색 카드가 열린 채 펜이 캔버스에 획을 긋고 있다. **비모달**: 열어 두고 색 바꿔 가며 칠한다. 카드가 캔버스를 가리는 부분은 왼쪽 위 ≈ 210×250뿐.
**16진수는 글자칸에 항상 보인다**(003F72 · FFF4DA · 93A2AE · 00F2FF · 00A4E0 · 00297A · FFF5D8) — 숫자 입력이 가능한 자리이나 영상에서 치지는 않는다.

**주사기(Injector) 13:17** 자막 「브러시 종류, 색상, 크기가 모두 추출되는 것을 볼 수 있습니다.」 → 주사기 = 기존 획을 찍으면 **브러시·색·크기 셋을 한 번에** 현재 설정으로 가져온다. (스포이드 = 색만; 16:37 「아이드로퍼를 사용하여 같은 색상을 추출」 — 색 카드 안 스포이드는 색만.)

**같은 답이 세 번 나온 것**(= 업계 합의):
1. 색은 **고리 + (사각|디스크)**, 16진수 칸, 스포이드. 견본은 그 아래 한 줄.
2. 지금 색은 **툴바의 원 하나**로 보인다(Feather · Procreate). Trace는 견본 칸 자체가 표시.
3. 크기·불투명은 **툴바에 상시**(점 또는 슬라이더). 카드 안에 숨기지 않는다.
4. **되돌리기·다시하기는 화면에 항상**, 못 누르면 흐림.
5. **획 끝에서 펜을 멈추면** 뭔가 된다(직선 보정 / 끝점 조절).
6. **선택된 도구 아이콘을 다시 누르면** 그 도구의 카드(Procreate) 또는 다음 모드(Feather).
7. 브러시는 **그림(획 견본 또는 도구 그림)**으로 고르고 이름은 작다.
8. 라벨 없는 아이콘 + 아이콘 한 굵기 + 둥근 알약/카드. **툴팁 없음(셋 다).**
9. 카드는 캔버스를 다 덮지 않는다(스튜디오 모달만 예외). 열어 둔 채 그릴 수 있는 쪽(Feather 2.x)이 더 편해 보인다.

**서로 다른 답**(= 우리가 골라야 하는 것):
- 크기 단위: mm(Feather) / %(Procreate) / 8단 눈금(Trace). 우리는 «면 위에 실치수»니까 **mm**가 맞고, Trace처럼 **눈금 몇 개**를 상시로 두는 절충이 가능.
- 지우개: 획 단위(Feather) / 픽셀(Procreate) / 펜 슬롯(Trace). 67-0-6 = 「덮임을 빼는 획」 + 고정 칸 → Trace 답.
- 채우기: 없음 / 색 끌어 놓기 / 도구+탭. 우리는 «면이 이미 있다» → 색 원을 **면으로 끌어 놓기**가 자연스러움(Procreate 답을 우리 면에).
- 브러시 수: 6 / 200 / 12. 우리는 196 CC0을 들었으니 Procreate식 **세트 → 견본** 두 칸이 필요하고, Trace식 **슬롯 6~7**이 상시.
