> 자리·종류·글자 라벨·툴팁은 원장(DOM 실측 · «눌린다» = 가운데의 elementFromPoint가 자기 #97)에서 **그대로**, «언제 쓰는가·판정·근거»는 사람 판정(judge69 — 지시 §2 규칙 넷 · DIRECTION 「시작은 종이다」 · UX-FLOWS §A-0/§C-0/§D-0/§E).
> 상태(렌즈 통은 «카메라가 선 문서»에서만 — 새 문서에서는 렌즈 단추가 disabled라 상자 하나를 그려 세운 뒤 열었다 · 절차·모달의 «더»는 그 카드가 열린 상태 기준): 기본(새 문서 · 연필 — 「아무 도구도 안 든 상태」는 이 앱에 없다: 도구 하나는 늘 들려 있다) · 도구:연필/펜/지우개 둘/면/칠(그 도구를 들 때 «더» 나타나는 것 — 같은 id라도 자리가 다르면 새 것) · 카드:파일/설정/보기/치수판 · 통:렌즈/자/손/롤/브러시 목록/색상 휠(그 손잡이를 누르면 «더» 나타나는 것) · 절차:필압 보정(설정에서 켜면) · 개발(?dev=1 — 없으면 DOM에 없다 · 존재 셈 0/3).
