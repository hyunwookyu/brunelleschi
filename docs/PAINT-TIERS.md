# 칠 — 표현기법과 도구의 단계

> **이것은 「뺄 것」의 목록이 아니라 「먼저 볼 것」의 순서다.**
> 62가 오면 mypaint-brushes 196개가 한꺼번에 들어오므로, 단계가 정하는 것은
> **무엇을 먼저 확인하고 다듬는가**이지 무엇을 넣는가가 아니다.
>
> ⛔ 세션이 「건축에서는 그걸 안 쓴다」로 매체를 잘라내지 마라 —
> 사람이 명시적으로 금지했다(2026-09-04). 이 문서의 아래 단계도 그 뜻이 아니다.

---

## 0층 — 없으면 «무엇을 얹어도» 나쁘다

도구가 아니라 엔진이다. **하나라도 빠지면 그 위의 196개가 전부 나빠 보인다.**
지금까지 열네 라운드가 이 층을 안 세우고 위층만 만졌다.

```
① 올바른 알파 합성          흰 테 0. premultiplied 선형광 · rgb ≤ a 단언
② 획 안 / 획 사이           한 획 안은 안 쌓이고, 획끼리는 쌓인다
③ 안료 혼합                 겹치면 물감처럼 섞인다 (파랑 위 노랑 = 초록)
④ 필압 → 농도·굵기          농도가 굵기보다 가파르다
⑤ 종이 결                   «면 고정». 굵기와 무관. 격자가 아니다
⑥ 미리보기 == 확정본        그은 것과 남은 것이 같다
```

**전부 62가 세운다.** ⑥은 59가 세웠다.

---

## 1층 — 이 앱의 뼈대. 없으면 앱을 못 쓴다

건축 스케치에서 «매일» 쓰는 것.

```
연필        2H · HB · 2B · 4B · 8B          mypaint 7종 + classic
잉크펜      제도 펜 · 볼펜 · 딥펜            10종 이상
마커        굵기 둘 이상 · 겹치면 진해진다     5종
색연필      단색 및 겹쳐 쌓기                 (연필 엔진 + 색)
지우개      거친 것 · 정밀한 것               ✓ 이미 있다
단색 채우기  면을 한 색으로                    ✓ 이미 있다
```

**기법**: 필압 · 크기 슬라이더 · 색상 휠 · 재료 팔레트 — 전부 이미 있다.

---

## 2층 — 도면이 «그림»이 되는 것. 건축 표현의 고전

건축 투시도·입면 렌더링이 실제로 쓰는 것들이다. **여기가 이 앱의 성격을 만든다.**

```
수채          투명 채색 · 겹쳐 쌓기 · 가장자리 고임        11종 (deevad · tanda)
목탄 · 콘테   문지르기 · 종이 결                          5종
파스텔        분필 결                                     ⚠ 1종뿐 — 만들어야 한다
에어브러시    하늘 · 그라데이션 · 부드러운 그림자           5종
스머지·블렌더  칠한 것을 문질러 섞는다                      12종 이상
해칭 · 재료 표현                                          ✓ 이미 있다 (49 · 52)
```

**기법**: 안료 혼합(0층 ③) · 젖은 붓(smudge) · 알파 잠금(칠한 데만 다시 칠하기)

---

## 3층 — 회화. 「그림 그리는 감각」의 본령

사용자가 화가이므로 **빼지 않는다.** 다만 0~2층이 선 뒤에 다듬는다.

```
유화 · 아크릴   두껍게 · 젖은 채로 섞기                   16종 (tanda · Dieterle)
나이프          긁기 · 펴 바르기                          6종
과슈            불투명 수채                               ⚠ 이름으로 «없다» — 아크릴에서 만든다
젖은 붓         wet-on-wet · 붓의 부분마다 다른 색을 문다   smudge_bucket 256개
임파스토        두께가 빛을 받는다                         ⚠ mypaint에 «없다» — dli/paint(MIT)
```

**임파스토만 별도 엔진이다.** 나머지는 62가 다 가져온다.

---

## 4층 — 나중. 또는 아마 안 쓴다

빼는 것이 아니라 **맨 뒤**다. 필요해지면 그때 연다.

```
스플래터 · 스프레이 특수                          있으면 쓴다. 급하지 않다
털 · 잎사귀 같은 형태 브러시                      건축엔 조경에 쓸 수는 있다
포스터라이즈 · 하프톤 · 디더                       그래픽 처리지 그리기가 아니다
1픽셀 · 픽셀아트                                  이 앱의 것이 아니다
필터 (블러 · 샤픈 · 색보정)                        그림 앱의 것이지 이 앱의 것이 아니다
Rebelle급 수채 유체 (번짐 · 블룸 · 마름 · 기울임)   별도 연구 과제. 지금 손대면 라운드를 삼킨다
```

## 기법 축 — 도구와 별개로 본다

```
층   기법                          상태
──   ────────────────────────────  ──────────────────────────────────
0    필압 → 농도 · 굵기             ✓ 있다
0    안료 혼합 (겹침)               62
0    종이 결 (면 고정)              62 — 지금은 격자라 틀렸다
1    블렌드 모드 (곱하기 등)         부분 (마커가 multiply)
1    크기 · 색 · 불투명도            ✓ 있다
2    속도 → 농도 · 굵기             ✓ 61이 축을 열었다
2    젖은 붓 (smudge)               62
2    알파 잠금                      없다 — 2층
2    대칭 그리기                    없다 — 건축에 유용하다. 2층으로 올린다
3    기울기(tilt) → 폭 · 결          없다. 애플펜슬. 연필 눕히기
3    방향 → 납작한 팁                61이 축을 열었다(dirK)
3    비트맵 팁                      63 — 마른 매체의 «성격»이 여기서 온다
3    임파스토 (높이 → 조명)          65
4    배럴 회전                      맨 뒤
4    브러시별 레이어                 우리는 «겹»과 «면»이 그 자리다. 재고 필요
```

## 언제 오는가

```
62  0층 전부 + 1·2·3층 «브러시»가 한꺼번에      ← 여기가 제일 크다
63  비트맵 팁 → 마른 매체(연필·목탄·파스텔)의 성격이 완성된다
64  그리는 화면 — 면 정면으로 가서 그린다
65  임파스토 · 유화 (dli/paint)
그 뒤  과슈 프리셋 · 알파 잠금 · 대칭 · 기울기
맨 뒤  4층
```

⛳ **62가 끝나면 3층까지의 브러시가 대부분 손에 있다.**
그때 할 일은 «만드는 것»이 아니라 **사진을 보고 고르고 다듬는 것**이다.
