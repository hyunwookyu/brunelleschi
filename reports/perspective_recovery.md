## §3.8 개정안 (2F 근거)

> 기존: "투시 단독 복원은 불안정. 평면과 함께 있을 때만 성립."
> **개정**: 투시 단독에서 **카메라 방향은 소실점으로**(2B), **종횡비는 footprint가 직사각이면
> 직각가정으로 결정 가능**(2F-a, fSpy 2-VP). **비직교 footprint(L자·凹자)는 종횡비 미결정 →
> 평면 병용 또는 발화 앵커 필요.** 건축 평면은 직교폴리곤 위주(§6.2)이나 단일 사각형이 아닌
> 복합 형태는 각 직사각 부분에 직각가정 적용 후 조합해야 함(후속).

## 2F — 사전지식으로 종횡비 결정 (2A 정답 대비, n=150)

**2F-a 직각 가정** (직사각형 → 종횡비 탐색, 재투영오차 최소):
| footprint | 등급 | plane_iou 중앙/p10 | 종횡비 상대오차 중앙 |
|---|---|---|---|
| 직사각 | L1 | 0.96 / 0.45 | 0.04 |
| 직사각 | L2 | 0.85 / 0.42 | 0.16 |
| 직사각 | L3 | 0.74 / 0.47 | 0.35 |
| 비직교 | L1 | 0.64 / 0.38 | 0.48 |
| 비직교 | L2 | 0.62 / 0.31 | 0.54 |
| 비직교 | L3 | 0.63 / 0.32 | 0.53 |

→ 직사각은 종횡비 결정 가능(L1-L2 IoU 0.85+), 비직교는 붕괴. p10이 낮아(0.4대) 직사각도
꼬리 케이스(퇴화 시점)는 실패 — 중앙값이 헤드라인, 신뢰성은 조건부.

**2F-d 발화 앵커**: 치수 발화 있으면 종횡비 확정(자명, §3.3). 코퍼스 치수발화율 0.73%
(스케치 자막 기준) — 투시영상 치수발화율은 2G 실영상서 재측정.

**2F-b 수직 직립 / 2F-c 반복 모듈**: 구조만. 수직획·모듈(창·기둥 등간격) 검출 필요 → 후속.
검출가능 영상비율은 2G에서.

## 2I — 꼬리 실패 사전판정 (p10 0.4대 처리)

`stage_perspective/failure_gate.py`. n=400(퇴화 시점 포함).
- 전체 실패율(IoU<0.6) 0.205, 중앙 IoU 0.82.
- **기하 게이트**(원거리 VP/퇴화각/f²≤0): recall 0.51, precision 0.24, 통과분 실패율 0.18(전체 0.205 대비 소폭↓).
- **fit_error 게이트: 실패 미예측**(recall ~0.05). **실패는 재투영 낮아도 발생** — 종횡비 모호가 내재적, fit_error로 안 잡힘.

→ **결론: 꼬리 실패는 fit_error로 사전판정 불가**(내재적 모호). 퇴화 시점만 기하로 일부 예측.
실패를 미리 아는 것이 목표(§5.3)였으나 **상당 부분은 사전판정 불가** → 신뢰 요구 시 평면/앵커.

## 2J — 치수 발화율 (§3.3 앵커 전제 점검)

`stage5/dimension_rate.py`. 현 22자막(설계/스케치) 영상별:
- 전체 0.75%, **영상별 중앙값 0.0%**, 치수 발화 있는 영상 **4/12뿐**, 최대 4.5%.

→ **§3.3 "앵커가 핵심 경로"는 명시적 치수화 세션에 한정.** 대부분 내레이션/크리틱 세션은
치수 발화 0 → **무차원 유지·비례전파(§3.5)가 주 모드**, 앵커는 간헐적. 작도 교육 영상 분리는 2G 후.

## 2A — 평면↔투시 대응 (지도 신호 있음)

`stage_perspective/reconstruct.py` + `evaluate.py`. 대응 4점 → 카메라(stage3 재사용)
→ 호모그래피 역으로 Z=0 역투영 → 원본 평면 IoU. 노이즈=등급 프록시(L1 2px/L2 8px/L3 20px), n=200.

| 등급 | plane_iou 중앙/p10 | 카메라 fit_error 중앙/p95 | reproj 중앙 | 실패율 |
|---|---|---|---|---|
| L1 (자·구축선) | 0.989 / 0.979 | 0.0014 / 0.0026 | 0.0014 | 0% |
| L2 (프리핸드 일부) | 0.962 / 0.926 | 0.0046 / 0.010 | 0.0046 | 0% |
| L3 (컨셉) | 0.942 / 0.844 | 0.0073 / 0.023 | 0.0073 | 0% |

**해석**: 4점 대응이 주어지면 역투영 평면 복원은 노이즈에 견고(L3서도 IoU 0.94). 역경로(§3.8
투시→평면)는 대응이 있을 때 수학적으로 성립·실용적. 무노이즈 round-trip IoU=1.0(정확).

**주의**: 이 IoU는 **대응이 주어진 경우**(2A)의 역투영 단계 품질이지, 투시 단독(2B) 답이 아니다.
`ortho_residual`은 합성 truth 사각형이 비직교(비정형 quad)라 의미 제한 — 직사각 truth로 재측정 필요.

## 2B — 투시 단독 (대응 없음)

`stage_perspective/construction.py`. 구축선(초반 장직선) → 소실선 교점 클러스터 → VP.
**합성 검증**: 바닥 그리드 5선 → VP 추출 오차 **0px**(해석적 VP와 일치), support 5, 구축잔차 1.0.

**핵심 한계(§3.8)**: VP는 카메라 **방향**을 주나, 세계 사각형의 **종횡비**를 주지 않는다.
같은 투시가 여러 (형태×카메라) 조합과 정합 → 미결정. 직교성 사전지식·알려진 치수·평면 병용
중 하나가 있어야 형태가 확정된다. 이것이 §3.8 "평면 병용 필수"의 실체.
