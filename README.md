# Brunelleschi

**투시도와 입체를 동시에 보면서, 실시간으로 입체를 만든다.**

빈 화면에 투시도를 그린다. 소실점이 잡히는 순간 그때까지의 획이 3D로 올라가고,
그 뒤로는 시작점 스냅·축 추론·미리보기가 실시간으로 돈다.
**사용자는 계속 종이에 투시도를 그린 것이고, 3D 공간을 조작한 적이 없다.**

> **이름** — **필리포 브루넬레스키**(Filippo Brunelleschi). 1415년경 피렌체 산 조반니
> 세례당 앞에서, 판에 그린 그림에 구멍을 뚫고 거울에 비춰 실제 건물과 겹쳐 보이게 했다.
> **선 투시가 눈에 보이는 것과 맞는다**는 것을 작도가 아니라 **실험으로** 보인 첫 사례다.
> 이 도구가 하려는 것도 같다 — 그린 투시도와 세워진 입체가 **같은 픽셀에 놓이는지**를
> 매 획마다 확인한다.

## 이 도구가 무엇인가

**제도판 위에 놓인 종이와 제도용구**다. 메뉴와 도구모음이 아니다.
쓸 사람은 **공간과 투시를 이해하는 사람**(건축가·디자이너)이고, 초보자용 가드레일을 두지 않는다.

- 입력은 **손 획**이다 — SketchUp의 선 도구를 손으로 쓰는 것에 가깝다.
- **고유한 것은 둘뿐이다**: ① 빈 화면의 2D 획이 카메라를 정하는 것 ② 소실점이 하나 더
  잡히면 투시 차수가 승격되고 전부 다시 풀리는 것. 나머지(스냅·축 판정·선 도구·뷰포트·편집)는
  **SketchUp/Rhino의 검증된 메커니즘**을 그대로 따른다.
- 화면의 말은 **정확한 것**을 쓴다 — 「오스냅」을 「점 물림」으로 바꾸지 않는다.
  아날로그를 만드는 것은 **아이콘과 배치**다([`docs/DRAFTING-MAP.md`](docs/DRAFTING-MAP.md)).

## 어떻게 시작하는가

```
① 빈 화면에 투시도를 그린다 (아직 2D)
② 소실점이 잡히면 카메라가 확정되고, 그때까지의 획이 3D로 올라간다
③ 이후는 실시간 — 시작점 스냅 · 축 추론 · 미리보기
④ 소실점이 하나 더 잡히면 차수가 승격되고 전부 다시 풀린다
```

지평선은 **긋는 것이 아니라 이미 있다**(화면 세로의 절반). 첫 획이 지면에 놓이고,
깊이선과 지평선의 교점이 소실점이다 — 판정도 대기도 없는 계산이다.

화면은 네 자리다(대응표 §6):

| 자리 | 무엇 |
|---|---|
| **위 왼쪽** | **종이** — 썸네일 스트립(늘 표시) + 그 아래 겹 요약 |
| **위 오른쪽** | **눈** — 작도 시점으로 · 전체 화면 · 표시 토글 |
| **오른쪽 세로** | **손** — 자(스냅) · 연필통 · 펜 · 지우개 둘 · 면 · 굵기 · 롤 둘 · 치수 |
| **오른쪽 맨 아래** | **서랍**(접힘) — 파일 · 종이 질감 · 진단 |

**종이**는 한 장씩 배타적이고(도면집의 한 장), **겹**(트레이싱지·옐로)은 가산적으로 여럿을
동시에 얹는다. 종이 띠의 **셔터**를 누르면 지금 보고 있는 시점이 한 장으로 남는다.
겹을 얹으면 지금 시점이 자동으로 굳는다 — 「이 각도에서 시작한다」는 뜻이기 때문이다.

**두 겹의 성질이 다르다**: 트레이싱지는 종이와 같은 메커니즘(축 스냅·3D)이고,
**옐로는 2D 자유 스케치**다(축·3D·오스냅이 전부 안 돈다 — 「자를 치운 종이」).
옐로를 얹는 순간 그 아래 3D가 한 번 **은선 계산**을 거쳐 밑그림으로 구워진다
(보이는 선 `F` · 가린 선 `H`).

## 무엇을 저장하는가 — `.brnl`

JSON 한 파일이다. **파생은 저장하지 않는다** — 카메라·소실점·리프팅은 열 때 다시 계산된다.

담기는 것: 프레임 · 획(끝점 둘 + 손 점렬 + 점별 필압) · 면(경계 획의 id 차례) ·
종이(시점·썸네일) · 겹 · 밑그림 · 치수 단위와 기준 획 · 작도 시점.
**자동 저장**은 `localStorage`로 돌고(가정 상한 5MB), 70%를 넘으면 실패 **전에** 알린다.

## 무엇을 안 하는가

- **내보내기(SVG·DXF·3DM)가 없다.** 설계가 안 됐다.
- **그림자·재질·조명이 없다.** 면은 옅은 채색이고 **면끼리 서로 안 가린다**(화면의 규약) —
  가림은 옐로에 굽는 밑그림에서만 계산한다.
- **선택과 이동이 없다.** 고치는 방법은 지우고 다시 긋는 것이다.
- **온보딩·튜토리얼이 없다.** 공간을 아는 사람을 전제한다.
- **프리핸드 보존이 없다**(옐로 제외). 3D로 올라가는 획은 직선 세그먼트가 되고 손떨림은 버린다 —
  다만 `raw`(손 점렬)는 계속 저장하므로 나중에 표현 계층으로 되돌아온다.
- **협업·계정·클라우드가 없다.** 브라우저 안에서 끝난다.

## 개발

```bash
cd web2 && npm install && npm run dev
```

| 명령 | 무엇 |
|---|---|
| `npm run dev` | 개발 서버(5301) |
| `npm run build` | 배포 빌드 |
| `npm run typecheck` | 타입 |
| `npx vitest run` | 단위 |
| `npx playwright test --workers=1` | e2e(dpr 1·2 두 판) |
| `npm run deploy:check` | 배포 확인 — 원격 main·화면 빌드 식별자 대조 |

측정 하네스는 **`LEDGER=1`에서만** 원장(`stage0/out/*.json`)을 쓴다.
`python selfcheck.py`가 그 원장들을 훑어 의심 수치를 낸다.
